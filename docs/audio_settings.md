# 오디오 설정

2026-10-23: 공통 톱니바퀴 메뉴 → **설정**의 오디오 설정에 세 가지 슬라이더를 제공한다.

| 항목 | 조절 대상 | 저장 키 | 기본값 |
| --- | --- | --- | --- |
| 마스터 볼륨 | 게임 전체 소리 | After333.Audio.MasterVolume | 50% |
| 배경음악 볼륨 | 로비·전투 음악 | After333.Audio.MusicVolume | 100% |
| 효과음 볼륨 | 배경음악을 제외한 게임 효과음 | After333.Audio.EffectsVolume | 100% |

효과음에는 버튼·카드 터치·골드 버튼, 카드 드로우·이동, 캐릭터 공격·피격·사망과 마법/VFX 소리가 포함된다. 기존 소리·개별 Inspector 음량은 바꾸지 않고 효과음 설정값을 곱한다. 실제 광고 영상처럼 외부 SDK가 자체 재생하는 오디오는 Unity 게임 효과음 재생 경로에 포함되지 않는다.

- 마스터 50%·효과음 50%라면 기존 개별 효과음 음량의 25%로 출력한다. 배경음악 슬라이더는 효과음에 영향을 주지 않고, 효과음 슬라이더도 음악에 영향을 주지 않는다.
- 효과음은 재생 중에도 즉시 변경한다. 0%면 효과음만 음소거한다. 소스 재사용이나 연속 재생으로 같은 설정값이 누적 적용되지 않는다.
- 변경값과 퍼센트 표시는 즉시 반영한다. 뒤로/메뉴 닫기, 비활성화, 앱 일시정지/종료의 기존 저장 경로로 PlayerPrefs에 저장한다. 설정을 다시 열면 저장된 값으로 슬라이더를 맞춘다.
- 마스터 볼륨 저장값이 없으면 처음 설치 기본값 50%를 적용한다. 이미 저장된 마스터 음량은 덮어쓰지 않는다.
- 효과음 저장 키가 없는 기존 설치에서는 100%로 시작하여 이전의 개별 소리 크기를 유지한다. 기존 마스터·음악 설정값은 유지한다.
- 시작·드래프트·덱 빌딩·전투·보유 카드·상점의 공통 설정에 적용한다. 기존 튜토리얼 연습 중 설정 변경 제한은 유지한다.

## 구현과 추가 효과음 연결

`After333AudioSettings`가 저장값과 변경 이벤트를 관리한다. 마스터는 기존 `AudioListener.volume`, 음악은 `BackgroundMusicVolumeTarget`을 사용한다.

게임 효과음의 재생은 `After333SoundEffects.PlayOneShot(source, clip, volumeScale)`을 사용한다. 기존 모든 Project333 효과음 호출을 이 경로로 연결했다. 이 함수는 기존 AudioSource를 재사용하면서 `SoundEffectVolumeTarget`에 등록한다. 한 GameObject에 두 개의 소스가 있어도 각 소스의 원래 음량을 별도로 보존한다. 변경 이벤트로 원래 소스 음량 × 효과음 설정값을 적용하므로 이미 재생 중인 one-shot도 조절된다. 마스터는 여기서 다시 곱하지 않는다.

씬에 미리 저장된 AudioSource는 `Project333RuntimeSettings`의 씬 로드 처리에서 한 번 등록한다. `BackgroundMusicVolumeTarget`이 있는 음악 오브젝트는 제외한다. 새 런타임 효과음도 공통 PlayOneShot을 사용해야 즉시 등록된다. one-shot 이외의 별도 재생이 필요하면 `After333SoundEffects.RegisterSource(source)`로 먼저 연결한다. 매 프레임 전체 소스를 검색하지 않는다.

`GlobalSettingsMenuController`는 EffectsVolumeLabel / EffectsVolumeSlider / EffectsVolumeValueText를 기존 오디오 패널에 추가한다. 과거 저장된 높이 560 패널도 최소 높이 720으로 확보해 세 번째 슬라이더와 뒤로 버튼이 겹치지 않게 한다. 기존 슬라이더 오브젝트와 Inspector 연결을 유지하고 반복 구성 시 중복 생성하지 않는다. 씬 전체를 재저장하지 않아도 런타임에서 추가된다.

2026-10-24 추가된 [승리·패배 효과음](battle_outcome_presentation.md)도 효과음 볼륨을 따른다. 배너의 재사용 AudioSource를 RegisterSource로 연결하며 배경음악 볼륨과 분리한다.

## 검증과 반영 범위

- Unity 6000.3.12f1 독립 검증 프로젝트 **16/16 통과**: 새 효과음 검사 9개, 기존 음악 3개·설정 빌드 라벨 2개·이동 효과음 2개.
- 기존 저장값 호환·범위 제한·저장/로드, 여섯 씬의 세 번째 행·기존 패널 크기 보완·중복 방지·슬라이더/뒤로 버튼 미겹침을 검사했다.
- 실제 Play 진입 후 이미 재생 중인 효과음 조절·음소거, 같은 GameObject의 복수 소스, 소스 재사용·비활성화/재개, 음악과 마스터 분리, 실제 설정 버튼/슬라이더와 세 종류 터치 효과음 연결을 검사했다.
- 현재 소스는 검증 복사본과 SHA256이 일치한다. 효과음의 raw PlayOneShot 호출이 공통 헬퍼 한 곳에만 남은 것도 확인했다. 증거는 세션 시각화 `EffectsVolume_20261023/AudioTests.xml`, `AudioTests.log`, `verification.json`, `task.patch`에 있다.
- 초기 검증 복사본에만 외부 LevelPlay SDK 구현을 잘못 포함해 컴파일이 멈췄다. 광고 SDK 없는 기존 격리 범위로 복구했고 운영/프로젝트 광고 코드는 변경하지 않았다. 이어 새 테스트의 빈 씬 생성 방식 오류 6건을 수정한 뒤 전체 16건이 통과했다.
- 실제 휴대폰 청취·사용자 앱 빌드/설치나 서버/DB 작업은 수행하지 않았다. 휴대폰에는 새 클라이언트를 빌드·설치하면 반영된다.

## 승리·패배 효과음별 기본 볼륨

`BattleOutcomeBannerView.cs`의 `_victorySoundVolume`과 `_defeatSoundVolume`으로 따로 조절한다(2026-10-26 현재 코드 초기값: 승리0.65·패배1; 분리 구현 당시에는 각각1). 승리만 줄일 때는 전자만 수정한다. 실제 출력은 해당 기준 볼륨 × 공통 효과음 볼륨 × 마스터 볼륨이다. 승리/패배 전용 소스는 각 최대1개씩 재사용하며 공통 설정을 따른다. 코드 수정 후 Play 재시작 또는 사용자 앱 재빌드가 필요하다.
