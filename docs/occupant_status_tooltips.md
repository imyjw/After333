# 소환물 미리보기의 버프·디버프

2026-10-08 사용자 용어 정의: **카드 미리보기 창**은 전투 소환물, 손패/덱 빌딩 제시 카드, 덱 빌딩·드래프트 덱 목록 등을 길게 눌렀을 때 나타나는 카드 이미지와 좌우 특수효과·아래 버프/디버프·위 적용 영향 툴팁 전체를 뜻한다.


2026-09-21 사용자 후속 요청: 카드 위·아래에는 **이름과 필요한 수치만** 표시한다. 상세 설명, 버프/디버프/상태/영향 접두어, 기간·해제 조건 안내는 표시하지 않는다. 좌우 고유 특수효과 설명은 유지한다.

## 위치와 형식

- 좌우: 기존 카드 고유 특수효과의 제목과 자세한 설명.
- 아래: 소환물에 붙은 원인별 능력치 버프, 디버프, 상태.
- 위: 해당 소환물에 영향을 주는 아군 주문력과 전장·플레이어 효과.
- 같은 원인의 능력치 증가는 합산한다. 수치가 0인 능력치는 생략한다.
- 위·아래 패널은 설명 영역을 숨기고 제목에 맞춰 높이를 줄인다. 버프·디버프·상태의 기존 구분 색은 유지한다.
- 길게 누르는 동안 현재 수치를 갱신한다. 만료된 상태는 사라지며 손을 떼면 모든 미리보기 영역이 함께 닫힌다.

## 아래 표시 목록

A/H/N은 현재 전투 상태의 실제 증가량이다. '체력 +H'는 최대 체력 증가량이며, 피해로 잃은 현재 체력을 뺀 값이 아니다.

| 효과 | 표시 예시 |
|---|---|
| 용사의 일반공격 처치 보너스 | 용사: 공격력 +33, 체력 +66 |
| 로봇 합체 | 로봇 합체: 공격력 +10, 체력 +20 |
| 마왕 부활 보너스 | 마왕 부활: 공격력 +33, 체력 +33 |
| 대환단 | 대환단: 공격력 +100 |
| 마나쉴드로 부여한 마법 방어력 | 마나쉴드: 마법 방어력 +20 |
| 플라즈마 쉴드로 부여한 물리 방어력 | 플라즈마 쉴드: 물리 방어력 +20 |
| 오크 족장의 유효한 source별 오라 합 | 오크 족장 ×2: 공격력 +20, 체력 +20 |
| 버서커의 현재 증가량 | 버서커: 공격력 +12 |
| 웨어울프의 현재 동료 보너스 | 웨어울프: 공격력 +10 |
| 출처 정보 없는 예전 전투 상태 | 능력치 변화: 공격력 +7, 체력 +9 |
| 방전 | 방전 |
| 망각 | 망각 |
| 스턴 | 스턴 |
| 빙결 | 빙결 |
| 환술 | 환술 |
| 낙진 | 낙진 |
| 천라지망 | 천라지망 |
| 봉인 | 봉인 |
| 마왕 부활 대기 | 마왕 부활 대기 |
| 무적 | 무적 |

- 낙진 중첩, 무적 기간, 스턴·빙결 남은 시간, 봉인·부활 카운트 등은 전투 데이터에 유지하되 위 목록에는 설명 없이 이름만 표시한다.
- 무적은 기존 부착 기록의 존재를 나타낸다. 턴 조건이나 망각·방전 등으로 억제된 기록도 이름은 남으며, 기간 만료로 기록이 제거되면 사라진다.
- 버서커·웨어울프의 증가량은 현재 유효하고 0보다 클 때만 표시한다.
- 계정 강화, 일반 피해·회복, 종족, 고유 속공·연타·흡혈·관통 등은 아래 목록에 중복하지 않는다.
- 방어력 변화가 기록된 경우 같은 형식으로 '물리 방어력 +N', '마법 방어력 +N'을 표시한다.
- 오크 족장은 서로 다른 유효 source RuntimeId의 개수를 표시한다. source가 하나면 ×1을 생략하며, 족장이 퇴장하거나 효과가 억제되면 실제 남은 기여만 표시한다. 망각으로 지워진 기여를 표시 목적으로 되살리지 않는다.
- 트랩의 금색 ?/Xn은 마스터의 별도 공개 상태 표시다. 상대의 미발동 트랩 종류·비용·설명은 미리보기 위·아래에 노출하지 않는다. 실제 발동 중앙 공개와 재접속 개수 복원은 [트랩 규칙](battle_rules.md#트랩-trap)을 따른다.

## 위 표시 목록

| 효과 | 표시 예시 |
|---|---|
| 현재 활성 아군 소환물의 주문력 합 | 주문력 +30 |
| 마법 증폭진의 중첩 합 | 마법 증폭진: 주문력 +20 |
| 현재 위치에 적용되는 파이어월 | 파이어월: 마법 피해 30 |
| 현재 위치에 적용되는 생화학폭탄 | 생화학폭탄: 고정 피해 25 |
| 해당 전장에 적용되는 시한폭탄 | 시한폭탄: 물리 피해 30 |

- 아군 주문력과 마법 증폭진은 출처가 다르므로 별도 항목으로 표시한다.
- 범위 피해는 현재 위치가 범위에 포함될 때만 표시한다. 피해량에는 현재 시전자의 주문력을 반영하고 대상 방어·피해 보호·방전 배율은 실제 피해 판정에 맡긴다.
- 같은 원인의 범위 피해는 한 항목으로 묶는다. 예: '파이어월: 마법 피해 10 ×2, 마법 피해 30'. 별개의 피해 판정을 총합 피해 한 번으로 오해하지 않도록 숫자를 단순 합산하지 않는다.
- 남은 발동 횟수·발동 시점·해제 조건의 상세 설명은 표시하지 않는다.
- 소환물에 직접 영향을 주지 않는 자원 효과는 제외한다. 대환단은 2026-10-08부터 마스터 공격력 버프만 부여하며 기 생산 지속 효과를 등록하지 않는다. 2026-10-08부터 뉴클리어는 전장 지속 효과가 아니므로 위쪽에 ‘전장 낙진’을 표시하지 않는다. 사용 당시 받은 낙진만 해당 유닛·마스터의 아래 디버프 목록에 표시한다. 이후 소환물은 표시하지 않는다.

## 전투 상태와 구현

- 능력치의 출처·증가량은 CombatStatBuffState에 기록한다. 용사 처치·로봇 합체·대환단·마왕 부활의 실제 전투 적용 경로를 사용하며, 표시 코드가 전투 수치를 변경하지 않는다.
- 망각은 기존 능력치 기록을 지우고, 마왕 부활은 초기화된 실제 능력치로 기록을 다시 만든다. 소유권 이전은 기록을 유지한다.
- 서버 스냅샷·관전자별 상태 투영·AI 복제에서 출처 기록을 보존한다. 오래된 데이터의 출처는 추측하지 않고 '능력치 변화'로 표시한다.
- OccupantSpecialEffectTooltipCatalog는 좌우 설명, OccupantStatusTooltipCatalog는 위·아래 제목만 생성한다.
- TileTextView는 패널을 재사용하고 실제 TMP 제목 높이를 계산한다. CardPreviewTooltipLayout은 카드와 네 방향 패널을 배치한다.
- 화면 크기가 매우 작거나 효과가 이례적으로 많으면 전체 축소가 적용될 수 있다.

## 손패·드래프트·덱 빌딩 미리보기 통합 (2026-09-29)

- 손패 카드, 드래프트/덱 빌딩의 제시 카드 및 덱 목록의 길게 누르기 미리보기에도 동일한 좌우/아래/위 배치를 사용한다. `DeckCardPreviewOverlay`가 기존 `OccupantSpecialEffectTooltipCatalog`와 `CardPreviewTooltipLayout`을 재사용한다.
- 좌우에는 실제 카드 정의의 고유 특수효과 제목과 상세 설명을 표시한다. 유닛·건물뿐 아니라 마법의 복제도 표시한다. 카드 정의만으로 만든 설명용 상태는 전투에 배치하거나 변경하지 않는다.
- 아래에는 카드 자체의 현재 상태를 표시한다. 현행 손패 데이터의 임시 복제는 `임시 복제`로 표시한다. 2026-10-24 사용자 요청으로 이 항목에만 `사용하지 않으면 이번 턴 종료 시 손패에서 사라집니다.` 상세 설명을 추가한다. 다른 상태의 이름/수치 중심 규칙은 유지한다. 임시 사본 그림 오른쪽 위에는 글자 배지 없이 모래시계 아이콘을 표시한다. 아직 소환되지 않은 카드에 전장 소환물의 방전·낙진·용사 버프 등을 복사하지 않는다. 계정 강화는 기존 카드 능력치에 반영하며 별도 버프로 중복 표시하지 않는다.
- 손패 위에는 아군의 활성 주문력과 `마법 증폭진: 주문력 +n`을 출처별로 표시한다. 위치가 없는 손패에는 파이어월·생화학폭탄 같은 타일 범위 효과를 표시하지 않는다. 드래프트·덱 목록은 현재 적용된 전투 상태가 없으므로 좌우 고유 효과만 표시하고 빈 위/아래 영역은 숨긴다.
- 손패의 전투 상태는 BattleScreenPresenter → HandPresenter → 미리보기로 전달한다. 주문력/임시 복제 상태 및 스냅샷 교체를 추적하며, 유지 중인 로컬 상태도 0.15초 간격으로 확인한다. 표시 내용이 바뀌었을 때만 툴팁을 재배치한다.
- 한글을 지원하지 않는 기존 손패 대체 글꼴은 프로젝트의 NeoDunggeunmoPro 글꼴로 대체한다. 툴팁은 입력을 가로채지 않으며 놓기·취소·카드 교체 시 카드 이미지와 함께 닫힌다.
- 검증: 별도 Unity 검증 프로젝트에서 관련 116개 검사 통과. 1920×1080, 2340×1080, 1280×720 배치 및 테스트 렌더링 확인. 최초 회귀검사에서 누락된 검증용 TMP/한글 폰트 에셋을 보완하고, 기존 타일 EditMode 테스트에서 자동 호출되지 않던 OnDisable을 명시 호출하도록 정정했다. 근거: TempBuild/CardPreviewDetails_20260929/verified.xml, preview.png. 앱 빌드·기기 조작·서버 배포는 수행하지 않았다.


## 플라즈마 쉴드 (2026-10-01)

전투 중 부여된 물리 방어력은 `CombatStatBuffState`의 `PlasmaShield` 출처와 실제 누적 증가량으로 아래 버프 목록에 표시한다(예: 플라즈마 쉴드: 물리 방어력 +20). 강화 불가 카드로 새 시전마다 +10을 합산한다. 망각으로 제거되면 표시를 지우고 소유권 이전·온라인 복원 시 보존한다. 보호막 VFX는 시전 한 번의 연출이라 버프 목록의 지속 상태와 구분한다. 아직 소환되지 않은 손패/덱 카드에는 전장 대상의 방어 버프를 복사하지 않는다.

## 마나쉴드 (2026-10-01)

전투 중 부여된 마법 방어력은 `CombatStatBuffState`의 `SourceCardId: ManaShield`와 실제 누적 `MagicDefenseBonus`로 아래 버프 목록에 표시한다(예: 마나쉴드: 마법 방어력 +20). 강화 불가 카드로 새 시전마다 +10을 합산하므로 두 번 적용하면 +20이다. 플라즈마 쉴드의 물리 방어력과는 다른 출처·다른 능력치로 표시하며 한 값으로 합치지 않는다.

망각으로 제거되면 표시를 지우고 고독에 의한 소유권 이전·AI 복사·온라인 복원 시 증가량과 출처를 보존한다. 방전 중에는 저장된 버프를 보존하되 실효 방어력 0 규칙을 따른다. 아직 소환되지 않은 손패/덱 카드에는 전장 대상의 방어 버프를 복사하지 않는다. 마나 구체는 성공한 시전 때 한 번 표시하는 연출이고 영구 버프의 남은 기간을 뜻하지 않으므로, 구체가 사라져도 아래 버프 목록은 실제 전투 상태를 계속 표시한다.

## 전력 소모와 방전 설명 (2026-10-02)

- 기존 전력 유지비의 사용자 표시를 특수효과 `전력 소모:n`으로 통일한다. 좌우 툴팁 제목은 `전력소모: n`, 본문은 `내 턴 시작 시 n의 전력을 지불해야한다. 지불하지 못하면 '방전' 디버프가 부여된다.`이다.
- 이 툴팁이 있으면 좌우 고유 특수효과 목록에 `방전`의 자세한 설명도 항상 함께 표시한다. 전장·핸드·드래프트·덱 목록·보유카드 등 공통 미리보기 경로에 적용한다. 현재 방전되지 않았어도 설명을 보여주며 실제 상태를 변경하지 않는다.
- 실제 방전 상태는 기존처럼 카드 아래 `방전` 한 번으로 표시한다. 설명용 좌우 툴팁을 실제 부여된 디버프로 처리하지 않는다. 카드 위·아래의 간결한 이름/수치 표시 규칙은 유지한다.
- n 전력을 자동으로 지불하고 부족분은 골드로 1:1 대체한다. 전액 지불 불가 시 일부만 차감하지 않고 방전된다. 이 비용 규칙과 턴 시작 순서는 변경하지 않는다.
