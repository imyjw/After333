# 소환물 미리보기의 버프·디버프

2026-09-21 사용자 후속 요청: 카드 위·아래에는 **이름과 필요한 수치만** 표시한다. 상세 설명, 버프/디버프/상태/영향 접두어, 기간·해제 조건 안내는 표시하지 않는다. 좌우 고유 특수효과 설명은 유지한다.

## 위치와 형식

- 좌우: 기존 카드 고유 특수효과의 제목과 자세한 설명.
- 아래: 소환물에 붙은 원인별 능력치 버프, 디버프, 상태.
- 위: 해당 소환물에 영향을 주는 아군 주문력과 전장·플레이어 효과.
- 같은 원인의 능력치 증가는 합산한다. 수치가 0인 능력치는 생략한다.
- 위·아래 패널은 설명 영역을 숨기고 제목에 맞춰 높이를 줄인다. 버프·디버프·상태의 기존 구분 색은 유지한다.
- 길게 누르는 동안 현재 수치를 갱신한다. 만료된 상태는 사라지며 손을 떼면 모든 미리보기 영역이 함께 닫힌다.

## 아래 표시 목록

A/H/N은 현재 전투 상태의 실제 증가량이다. '체력 +H'는 최대 체력 증가량이며, 피해로 잃은 현재 체력을 뺀 값이 아니다.

| 효과 | 표시 예시 |
|---|---|
| 용사의 일반공격 처치 보너스 | 용사: 공격력 +33, 체력 +66 |
| 로봇 합체 | 로봇 합체: 공격력 +10, 체력 +20 |
| 마왕 부활 보너스 | 마왕 부활: 공격력 +33, 체력 +33 |
| 대환단 | 대환단: 공격력 +100 |
| 버서커의 현재 증가량 | 버서커: 공격력 +12 |
| 웨어울프의 현재 동료 보너스 | 웨어울프: 공격력 +10 |
| 출처 정보 없는 예전 전투 상태 | 능력치 변화: 공격력 +7, 체력 +9 |
| 방전 | 방전 |
| 망각 | 망각 |
| 환술 | 환술 |
| 낙진 | 낙진 |
| 천라지망 | 천라지망 |
| 봉인 | 봉인 |
| 마왕 부활 대기 | 마왕 부활 대기 |
| 무적 | 무적 |

- 낙진 중첩, 무적 기간, 봉인·부활 카운트 등은 전투 데이터에 유지하되 위 목록에는 설명 없이 이름만 표시한다.
- 무적은 기존 부착 기록의 존재를 나타낸다. 턴 조건이나 망각·방전 등으로 억제된 기록도 이름은 남으며, 기간 만료로 기록이 제거되면 사라진다.
- 버서커·웨어울프의 증가량은 현재 유효하고 0보다 클 때만 표시한다.
- 계정 강화, 일반 피해·회복, 종족, 고유 속공·연타·흡혈·관통 등은 아래 목록에 중복하지 않는다.
- 방어력 변화가 기록된 경우 같은 형식으로 '물리 방어력 +N', '마법 방어력 +N'을 표시한다.

## 위 표시 목록

| 효과 | 표시 예시 |
|---|---|
| 현재 활성 아군 소환물의 주문력 합 | 주문력 +30 |
| 마법 증폭진의 중첩 합 | 마법 증폭진: 주문력 +20 |
| 현재 위치에 적용되는 파이어월 | 파이어월: 마법 피해 30 |
| 현재 위치에 적용되는 생화학폭탄 | 생화학폭탄: 고정 피해 25 |
| 해당 전장에 적용되는 시한폭탄 | 시한폭탄: 물리 피해 30 |
| 현재 전장의 낙진 노출 효과 | 전장 낙진 |

- 아군 주문력과 마법 증폭진은 출처가 다르므로 별도 항목으로 표시한다.
- 범위 피해는 현재 위치가 범위에 포함될 때만 표시한다. 피해량에는 현재 시전자의 주문력을 반영하고 대상 방어·피해 보호·방전 배율은 실제 피해 판정에 맡긴다.
- 같은 원인의 범위 피해는 한 항목으로 묶는다. 예: '파이어월: 마법 피해 10 ×2, 마법 피해 30'. 별개의 피해 판정을 총합 피해 한 번으로 오해하지 않도록 숫자를 단순 합산하지 않는다.
- 남은 발동 횟수·발동 시점·해제 조건의 상세 설명은 표시하지 않는다.
- 대환단의 기 수급처럼 소환물에 직접 영향을 주지 않는 자원 효과는 제외한다. 전장 낙진은 마스터에 표시하지 않는다.

## 전투 상태와 구현

- 능력치의 출처·증가량은 CombatStatBuffState에 기록한다. 용사 처치·로봇 합체·대환단·마왕 부활의 실제 전투 적용 경로를 사용하며, 표시 코드가 전투 수치를 변경하지 않는다.
- 망각은 기존 능력치 기록을 지우고, 마왕 부활은 초기화된 실제 능력치로 기록을 다시 만든다. 소유권 이전은 기록을 유지한다.
- 서버 스냅샷·관전자별 상태 투영·AI 복제에서 출처 기록을 보존한다. 오래된 데이터의 출처는 추측하지 않고 '능력치 변화'로 표시한다.
- OccupantSpecialEffectTooltipCatalog는 좌우 설명, OccupantStatusTooltipCatalog는 위·아래 제목만 생성한다.
- TileTextView는 패널을 재사용하고 실제 TMP 제목 높이를 계산한다. CardPreviewTooltipLayout은 카드와 네 방향 패널을 배치한다.
- 화면 크기가 매우 작거나 효과가 이례적으로 많으면 전체 축소가 적용될 수 있다.
