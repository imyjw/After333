# After333 외부 PVP 테스트 빠른 안내서

**2026-10-20 운영 기록 갱신:** 서울 Lightsail + Caddy + PostgreSQL18로 이전했고 공개 주소는 `https://api.after333.com`, 운영DB는 `project333_live`다. 사용자 전환 결과에서 migration24개/latest`0024_elf_elder_card_id`를 확인했다. 아래 과거 날짜의 노트북/Tunnel·DB버전·미배포 문구는 당시 기록이다. 현재 실행·백업 절차는 [Lightsail 운영](lightsail_operations.md), 확인 범위와 남은 시험은 [현재 상태](current_project_status.md)를 우선한다. 오늘 원격 재확인을 수행하지 않았다.

이 문서는 개발자가 아닌 테스터가 After333 PVP를 빠르게 실행하고 문제를 보고하기 위한 안내서입니다. 2026-10-01 현재 소스 기준이며 실제 배포본 버전과 서버 주소는 개발자가 제공한 값을 사용합니다.

## 1. 준비물

- After333 빌드 폴더 전체
  - `.exe` 파일만 복사하면 안 됩니다.
  - `After333.exe`, `After333_Data` 폴더, Unity 관련 파일들이 함께 있어야 합니다.
- 서버 주소
  - 예: `http://192.168.0.10:7333`
  - 개발자에게 받은 주소를 그대로 사용합니다.
- 테스트 계정
  - 가능하면 각 테스터는 서로 다른 계정을 사용합니다.
  - 같은 계정으로 두 PC에서 동시에 PVP에 들어가면 중복 접속 안내가 뜰 수 있습니다.

## 2. 게임 실행 방법

1. 빌드 폴더 안의 `After333.exe`를 실행합니다.
2. 시작 화면의 `ServerSettingsPanel`에서 서버 주소를 입력합니다.
3. `Apply` 버튼을 누릅니다.
4. 시작 화면 상태 표시가 아래처럼 나오는지 확인합니다.
   - `Server: OK`
   - `DB: OK`
   - `Cards: OK`
5. 계정으로 로그인하거나 회원가입합니다.
6. 덱이 없다면 `Game Start`로 드래프트/덱 빌딩을 완료합니다.
7. Draft/덱 화면의 `전투` 버튼으로 일반 매칭을 시작합니다. `골드 던전 (남은 횟수/3)`은 티켓 3개로 시작한 현재 런에서 최대 3회 도전하는 별도 모드입니다. 자정·앱 재실행·재로그인으로 횟수가 초기화되지 않습니다.

## 3. 기본 테스트 흐름

아래 흐름이 정상적으로 되는지 확인합니다.

1. 게임 실행 후 서버 연결 상태가 `OK`로 표시된다.
2. 로그인 또는 회원가입이 된다.
3. 드래프트/덱 빌딩을 완료할 수 있다.
4. 두 계정이 `전투`를 거의 동시에 눌러 사람끼리 같은 전투에 들어간다. 기본 20초 동안 사람을 못 찾으면 서버 AI와 시작하므로, 사람 상대 테스트에서는 그 전에 두 번째 계정도 매칭한다.
5. 카드 사용, 유닛 소환, 이동, 공격, 마법 사용, 턴 종료가 양쪽 화면에 동기화된다.
6. 한쪽 게임을 끈 뒤 서버가 끊김을 감지한 시점부터 70초 안에 앱을 다시 실행하고 `전투 재접속`을 누르면 원래 전투로 돌아간다. 버튼의 서버 남은 시간을 기준으로 한다.
7. 전투가 끝나면 승패가 기록되고 Draft 화면 또는 Start 화면으로 정상 복귀한다.

## 4. 문제가 생겼을 때 보내줄 정보

문제가 생기면 아래 정보를 개발자에게 보내주세요.

- 문제 발생 시간
- 사용한 계정 이름
- 서버 주소
- 어떤 버튼이나 카드를 눌렀는지
- 화면에 나온 안내 문구
- 가능하면 스크린샷 또는 짧은 영상
- 같은 문제가 다시 재현되는지 여부

서버 PC에서 테스트 중이라면 개발자는 아래 명령으로 로그 묶음을 만들 수 있습니다.

```powershell
powershell -ExecutionPolicy Bypass -File C:\Project_333\Server\Project333.PvpServer\Tools\CollectPublicPvpSmokeEvidence.ps1 -BaseUrl 'http://127.0.0.1:7333' -TestLabel 'tester-issue' -Notes '문제 상황 메모'
```

다른 PC에서 테스트 중이라면 서버 로그는 개발자가 서버 PC에서 따로 수집하면 됩니다.

## 5. 자주 보이는 문제

- `Server: OFF`로 표시됨
  - 서버 주소가 틀렸거나 서버가 꺼져 있을 수 있습니다.
  - 같은 네트워크에서 브라우저로 `http://서버주소:7333/health`가 열리는지 확인합니다.

- `Game Start` 버튼이 비활성화됨
  - 서버 계정 로그인 또는 서버 연결이 실패했을 가능성이 큽니다.
  - 서버 주소 적용 후 상태 표시가 `OK`인지 먼저 확인합니다.

- 이미 진행 중인 PVP 전투가 있다는 안내가 뜸
  - 같은 계정으로 이미 PVP에 접속해 있을 수 있습니다.
  - 기존 전투 창을 닫거나 다른 계정으로 로그인합니다.

- 매칭 화면이 오래 유지됨
  - 상대 테스터가 아직 `전투`를 누르지 않았을 수 있습니다. 기본 20초 후에는 AI 전투로 전환될 수 있으므로 같은 서버에서 거의 동시에 시작합니다.
  - 두 명 모두 서로 다른 계정으로 같은 서버에 접속했는지 확인합니다.

- 재접속 버튼을 눌렀는데 전투가 이미 끝났다고 나옴
  - 상대가 전투를 끝냈거나 70초 서버 재접속 기한이 지났을 수 있습니다. 서버 장애·재시작으로 취소된 전투도 이어갈 수 없으며 그 취소에는 승패를 기록하지 않습니다.

## 6. 통과 기준

테스트 한 판 기준으로 아래가 되면 기본 PVP 흐름은 통과입니다.

- 두 계정이 같은 서버에 로그인된다.
- 두 계정이 PVP 매칭으로 같은 전투에 들어간다.
- 카드 사용, 이동, 공격, 마법, 턴 종료가 양쪽에 반영된다.
- 한쪽이 껐다 켜도 70초 안에 전투로 복귀된다.
- 전투 종료 후 승패가 기록되고 화면이 정상 흐름으로 돌아온다.
