# 트랩 - 반응 장갑 발동 연출

2026-10-01 사용자 요청으로 추가한 일회성 발동 연출이다. 설치할 때는 공통 비공개 트랩 그림만 보여 주며, 발동에 성공하면 실제 반응 장갑 카드 공개와 함께 배리어·폭발을 재생한다. 2026-10-01 후속 수정에 따른 현재 카드 정의는 발동 전력4(부족분 골드 대체), 상대 일반 근거리 유닛의 내 마스터 근접 공격 조건이다.

## 스프라이트

- `Assets/Project333/Resources/Project333/Vfx/ReactiveArmour/Activation.png`: 2048×1024 RGBA, 4×2 배열의 512×512 프레임 8개. 각 셀에 투명 여백을 두며 Point/FullRect, mipmap 없음, 압축 없음으로 네이티브 임포트한다.
- 첫 프레임은 금빛 중첩 배리어만 표시한다. 두 번째 프레임부터 공격자 쪽으로 섬광과 폭발이 퍼지고, 최대 폭발 뒤 파편·연기가 사라진다. 유닛이나 탄환은 스프라이트에 포함하지 않는다.
- 배리어 중심을 고정하는 피벗은 (160,256)이다. 기준 그림에서 폭발은 오른쪽으로 퍼진다. 런타임에서 실제 마스터→공격자 방향에 맞춰 회전한다.
- 원본은 내장 imagegen으로 생성했다. 원본·최종 프롬프트·균등 셀 포장 정보는 `Tools/Art/Source/ReactiveArmourVfx/`에 보존한다. 생성 원본 1774×887을 동일한 배율로 480×480 내용과 16px 여백의 512px 셀에 포장했으며 그림을 다시 그리거나 프레임별로 재정렬하지 않았다.
- 네이티브 Sprite Editor API 임포터는 `Tools/Art/ImportReactiveArmourVfx.cs`의 `Batch`다. 프레임 순서와 투명도·경계, 재실행 시 GUID/fileID 및 metadata 보존을 검사한다. 씬·카드·카탈로그를 수정하지 않는다.

## 전투 연결

`ReactiveArmourVfx`가 시각 효과를 담당하며 `BattleBootstrapper`가 성공 발동 정보를 연출 순서에 연결한다. 로컬과 AI 전투에서는 해결 전 스냅샷의 실제 마스터·공격자 identity를 보존한다. 온라인에서는 서버가 확정한 `TrapTriggered`의 소유자와 공격자 identity를 사용하므로 취소된 `AttackStarted`가 없어도 재생한다. 신규 설치 카드의 발동 조건은 공통 서비스가 `AttackType.Melee`로 판정하며 원거리 공격에는 새 발동 이벤트와 VFX를 만들지 않는다. 시각 효과가 발동 여부를 재판정하지 않는다. 수정 전 설치·복원된 트랩은 포착된 구 조건·비용을 유지하므로 서버가 확정한 해당 발동 이벤트도 정상 재생한다.

배리어는 두 몸체의 중심 사이, 공격자 가까이에 놓는다. 크기는 유닛 표시 크기를 기준으로 정한다. 연출의 방향·크기 계산은 양쪽 전장·대각선·긴 간격도 처리하지만, 그 기하 처리 능력이 원거리 공격의 트랩 발동 조건을 의미하지는 않는다. 첫 배리어 프레임은 0.12초 유지하고 0.42초에 폭발이 공격자를 덮으면 실제 사망 모션을 시작한다. 기본 효과 길이는 0.82초다. 화면 갱신이 늦으면 최대 폭발 직전 컷에서 기다렸다가 사망 시작과 최대 폭발을 맞추고, 뒤쪽 연출 0.40초를 보장한다. 마지막 0.10초는 자연스럽게 투명해진다. 실제 사망 모션과 연쇄 반응이 끝날 때까지 기존 전투 연출 대기를 유지하며 시간을 멈춰도 unscaled time으로 진행한다.

트랩에 따른 직접 파괴는 기존 서비스가 즉시 확정하며 VFX가 HP나 자원·승패를 바꾸지 않는다. 가짜 피해 수치·피격음·취소된 일반 공격 모션은 추가하지 않는다. 실제 연쇄 피해는 기존 표시를 유지한다. 부활 대기 마왕에는 영구 사망 연출을 붙이지 않는다. 이 작업에서는 별도 폭발 효과음을 추가하지 않았다.

공격자의 runtime identity가 바뀌거나 표시가 사라지면 효과를 정리한다. 전투 연출 취소·씬 비활성화·재접속에도 정리하며, 상태 복원만으로 이전 폭발을 다시 재생하지 않는다. 온라인 상태 갱신은 폭발과 사망 연출이 끝날 때까지 기다린다.

## 검증

아래 검증은 근접 공격 전용·전력4로 변경하기 전 연출 추가 작업의 기록이다. 이 후속 규칙 변경의 검증 결과로 해석하지 않는다. 당시 검증 결과와 입력 해시는 `TempBuild/ReactiveArmourVfx_20261001`에 기록했다. 네이티브 임포트의 8개 프레임·투명도·16px 경계·재실행 메타데이터와 GUID/fileID 보존을 통과했다. 관련 8개 Unity fixture의 201개 고유 검사에서 모두 통과 결과를 확인했으며 컴파일 오류는 없다. 첫 실행은 200/201 통과로 테스트용 캡처 카메라 위치 검사만 실패했다. 카메라 배치만 수정하고 새 연출 fixture 26개를 재실행해 26/26 통과했다. 두 실행 사이 제품 입력이 동일함을 확인하고 결과를 합쳤다. 양쪽 방향의 실제 Canvas 첫 프레임·최대 폭발 캡처 4장은 `previews/`에 보존했다. 사용자 앱 빌드·설치나 운영 서버 배포는 하지 않았다.
