# 런 종료 보상 상자

변경 기준: 2026-10-05 KST. 소스의 표시·복구 동작을 설명하며, 사용자 기기에 설치된 앱이나 운영 서버에 배포된 버전을 보증하지 않는다. 실행 검증과 배포 여부는 [인수인계](codex_handoff.md)의 최신 보상 상자 기록을 따른다.

## 표시 순서

일반 게임런이 서버 기준 33승 또는 3패로 끝나면 화면을 어둡게 하고 중앙에 닫힌 보상 상자를 표시한다. 상자의 틈에서는 금색 빛이 새어나온다. 기존 중앙의 단독 `보상 받기` 버튼 대신 상자를 눌러 연다.

상자를 한 번 누르면 중복 입력을 잠그고 같은 RunId로 보상 수령을 요청한다. 상자가 열리고 내부 빛이 밝아지는 애니메이션을 보여준 뒤 서버에서 확인한 보상 결과를 표시한다. 애니메이션 자체가 재화·카드를 지급하거나 보상을 다시 추첨하지 않는다. 실제 지급은 기존 서버 트랜잭션에서 한 번만 확정된다.

결과 창은 `보상 획득`, `최종 기록 N승 · N패`, 해당 런에서 지급된 골드, 선택적으로 지급 티켓, 카드 총 장수·종류 수, 카드별 이름·장수를 분리해서 표시한다. 현재 보유 골드는 이번 지급량과 구분한다. 같은 CardId는 합쳐 표시하고, 이름이 같은 서로 다른 카드는 합치지 않는다. 현재 최대 33승 보상 99장을 현재 보상 풀 39종 모두 받더라도 목록을 잘라내지 않고 스크롤해서 확인할 수 있다. 긴 카드명은 줄바꿈한다. 카드명은 리치 텍스트를 끈 일반 텍스트로 표시한다.

## 보상 권한과 복구

- 상자를 누르기 전에 앱을 종료하면 서버의 완료 런·미수령 보상은 그대로 남는다. 다시 로그인해서 해당 런을 이어 보면 같은 보상 상자를 연다. 자동으로 새 런을 만들거나 기존 보상을 버리지 않는다.
- 클릭 후 서버가 지급을 확정했지만 응답·연출·결과 확인 도중 앱을 종료할 수 있다. 확인하지 못한 결과 표시에는 계정·서버·RunId로 구분한 대기 정보를 사용한다. 다시 접속하면 시작 화면의 `보상 확인하기`로 닫힌 상자에 다시 진입한다. 사용자가 상자를 다시 눌러 열 때 같은 RunId의 원래 보상 영수증을 확인하고 결과를 보여준다. 로그인만으로 수령 요청을 보내거나 자동으로 개봉하지 않는다. 현재 지갑을 원래 영수증의 과거 잔액으로 되돌리지 않는다.
- 같은 RunId 재요청은 원래 골드·카드 지급 내용을 돌려주고 추가로 지급하지 않는다. 카드 데이터나 보상 후보가 바뀌어도 이미 지급한 보상을 다시 추첨하지 않는다. 다른 계정의 RunId로 영수증을 조회할 수 없다.
- 시작 화면은 인증된 같은 계정·서버의 최신 런이 완료 상태이고, 표시 대기 RunId와 일치할 때만 `보상 확인하기`로 해당 결과에 진입한다. 티켓이 없어도 결과를 확인할 수 있다. 진행 중인 새 런이 있으면 기존 이어하기를 우선한다. 다른 기기의 새 런으로 최신 RunId가 달라지면 옛 표시 대기로 새 런에 간섭하지 않는다.
- 표시 대기 정보는 로컬 연출 복구용이며 지급 권한이 아니다. 서버가 확인한 실제 보상만 표시하고, 결과의 `확인`을 눌러 표시를 마친 뒤 대기 정보를 정리한다.
- 보상 공식·희귀도 확률·랜덤 보상 포함 조건은 [메타 규칙](meta_rules.md#rewards)을 유지한다. 골드 던전 보상과 일반 런 보상은 별개다.

## 예외 상황과 처리 기준

| 상황 | 처리 |
| --- | --- |
| 상자를 여러 번 누름 | 요청·개봉 중에는 한 번만 처리한다. |
| 인터넷 끊김·서버 시간 초과 | 지급 실패나 취소로 단정하지 않는다. 같은 RunId로 결과를 다시 확인하며 확정 전에는 보상 결과를 만들지 않는다. |
| 서버 지급 후 응답 유실 | 기존 영수증을 재조회한다. 지급·카드 추첨은 한 번만 한다. |
| 원래 영수증 누락·손상·중복 | 서버는 `reward_receipt_unavailable`로 거절하고 재지급·재추첨하지 않는다. 운영자가 보존된 런·영수증을 확인할 수 있도록 오류를 유지한다. |
| 앱 중단·배경 전환·씬 종료 | 대기 표시 정보를 유지한다. 개봉 애니메이션을 처음부터 다시 보더라도 서버 보상은 중복 지급되지 않는다. |
| 계정 전환 또는 서버 주소 변경 | 이전 계정의 늦은 응답이나 로컬 대기 정보를 새 계정에 적용하지 않는다. |
| 0승·3패로 종료 | 상자는 정상적으로 열고 `이번 런에서 획득한 보상이 없습니다.`라고 표시한다. 보상 공식 변경이나 최소 보상 추가는 없다. |
| 카드 이미지·이름을 찾지 못함 | 지급받은 CardId·장수는 목록에서 빠뜨리지 않는다. 이름을 찾지 못하면 CardId로 표시한다. |
| 99장·긴 카드명이 한 화면에 안 들어감 | 중복 합산·줄바꿈·스크롤로 전부 표시하고 결과 창의 확인 버튼을 유지한다. |

추가 권장 사항: 다른 기기에서 이미 수령했거나 앱 데이터 삭제로 로컬 표시 대기 정보가 없어져도, 서버에 지급된 재화와 카드가 사라져서는 안 된다. 이 변경은 같은 계정의 지급 영수증 재조회로 중복 지급을 방지한다. 기기 간 `결과를 읽었는지` 동기화나 별도 보상 내역 화면은 새로운 기능이므로 이번 작업에 포함하지 않으며, 필요하면 그 기능의 보존·표시 정책을 별도로 정한다.
