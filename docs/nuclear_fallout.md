## 즉시 효과

- 카드 대상 타일을 선택하지 않고 자신의 행동 턴에 사용한다. 비용을 지불하고 지정한 손패 사본을 소비한다.
- 사용 즉시 상대 전장의 현재 마스터·유닛·건물 전체에 효과수치만큼 고정 피해를 한 번씩 입힌다. 기본 100이며 계정 강화 레벨을 한 번 적용한다.
- 즉시 피해는 아군 전장에 직접 적용하지 않는다. 상대 원자력 발전소가 피해로 파괴되면 기존 양쪽 폭발 효과 등 사망 연쇄는 정상적으로 처리한다.
- 광역 피해이므로 쉴더가 대신 받지 않고 은신도 피해를 피하지 않는다. 방어력·주문력은 적용하지 않는다. 무적·불굴·봉인과 방전 3배는 기존 고정 피해 규칙을 따른다.
- 한 시전의 전체 피해를 먼저 적용한 뒤 사망·파괴 효과와 연쇄를 해결하고 마스터 패배를 판정한다. 양쪽 마스터가 연쇄로 함께 사망하면 기존 승패 규칙을 따른다.
- 별도의 비피해 전체 파괴는 발생하지 않는다. 따라서 무적·불굴을 무시하던 이전 뉴클리어 파괴 판정도 사용하지 않는다.
- 같은 시전에서 사용 당시 상대 전장에 있는 유닛·마스터에게 각각 영구 낙진 +1중첩을 부여한다. 피해가 무적으로 막혀도 낙진은 부여되며, 건물과 봉인 상태는 제외한다.

## 영구 낙진

- 사용 당시 상대 전장에 있는 유닛(마스터 포함)에만 적용한다. 이후 소환되는 유닛에는 낙진을 물려주지 않는다. 다시 뉴클리어를 사용하면 그 시점의 대상에게 각각 +1만 부여한다. 건물은 새 낙진 중첩을 받지 않고 낙진 턴 시작 피해도 받지 않는다. 즉시 피해는 기존대로 적 마스터·유닛·건물 전체에 적용한다.
- 양쪽 턴 시작마다 중첩당 고정 피해 10. 2중첩은 고정 피해 20의 한 피해 묶음이다. 주문력·뉴클리어 강화 레벨은 이 값에 적용하지 않는다.
- 낙진 피해는 기존 무적·불굴·봉인·방전 피해 규칙을 적용한다. 방전이면 3배다. 망각은 낙진을 제거하지 않는다.
- 고독 등 소유권 이전에도 이미 받은 낙진을 유지한다. 배치·이동·소유권 이전·재접속·AI 복사는 저장된 소환물별 중첩만 유지하고 새 중첩을 부여하지 않는다. 이후 뉴클리어를 다시 맞으면 +1중첩을 추가한다. 과거 스냅샷의 전장 카운터는 호환용으로만 보존하며 신규 소환물에 적용하지 않는다.
- 봉인 상태에는 새 중첩을 부여하지 않고 피해도 주지 않는다. 봉인 해제·부활 시 전장의 과거 낙진을 새로 적용하지 않는다. 이미 받은 낙진은 봉인으로 삭제되지 않으며 해제 후 다음 턴 시작부터 피해가 재개된다.
- 턴 시작 순서: 자원 획득 뒤, 광역 지속 피해·전력 소모·로봇 공장·기본 드로우 전에 양쪽 낙진 피해와 파괴 연쇄를 처리한다. 모든 턴 시작 피해·파괴 처리 후 살아남은 소환물만 전력 소모를 지불하며, 죽은 소환물의 전력·대체 골드는 차감하지 않는다.
- 영구는 해당 전투가 끝날 때까지다. 새 전투에는 낙진이 이어지지 않는다.
- 사용자 제작 카드 이미지 `Assets/Project333/Resources/Project333/CardArtwork/Nuclear.png`와 원래 메타데이터를 보존한다. `StarterTen/Cards/Nuclear.asset`과 `StarterTenCardCatalog`에 등록하며 JSON 카드 정의와 기존 시전 경로를 사용한다.
- 2026-09-30 후속 요청으로 덱 빌딩·랜덤 보상에 포함한다. 드래프트 첫 레전더리 선택 후보와 기존 강화 가능 레전더리 보상 후보에 들어가며, 카드 피해·강화·낙진 규칙은 변경하지 않는다.
