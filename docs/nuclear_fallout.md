# 뉴클리어와 낙진

- 시전 시 마스터와 봉인 중인 소환물을 제외한 양쪽 전장의 모든 소환물을 동시에 파괴한다. 무적·불굴은 파괴를 막지 않는다.
- 파괴·사망 시 효과는 기존 조건을 따른다. 원자력 발전소 폭발은 마스터도 피해를 받으며, 활성 마왕은 부활 대기 봉인에 진입한다. 망각·방전·봉인에 따른 효과 억제는 유지한다.
- 상대 전장에 영구 낙진 중첩 +1. 기존 소환물과 앞으로 소환될 유닛·건물에 적용하며 마스터는 제외한다.
- 낙진: 양쪽 턴 시작마다 중첩당 고정 피해 10. 2중첩은 고정 피해 20의 한 피해 묶음이다. 주문력은 적용하지 않는다.
- 낙진 피해는 기존 무적·불굴·봉인·방전 피해 규칙을 적용한다. 방전이면 3배다. 망각은 낙진을 제거하지 않는다.
- 고독 등 소유권 이전에도 이미 받은 낙진을 유지한다. 어느 전장에서 몇 중첩까지 적용받았는지 보존하여 같은 전장을 오가거나 재접속해도 중복 부여하지 않는다. 다른 전장의 새로운 낙진은 추가로 적용한다.
- 봉인 상태에는 새로운 중첩 부여와 피해를 보류한다. 봉인이 풀리면 현재 전장의 누적 낙진을 적용하고 다음 턴 시작부터 피해를 받는다. 이미 받은 낙진도 봉인으로 삭제되지 않는다.
- 턴 시작 순서: 기존 자원 획득·유지비·로봇 공장 뒤, 기존 광역 지속 피해·기본 드로우 전에 양쪽 낙진 피해를 함께 적용하고 파괴 처리를 한다.
- 영구는 해당 전투가 끝날 때까지다. 새 전투에는 낙진이 이어지지 않는다.
- 별도 카드 이미지·씬 에셋은 아직 등록하지 않았다. JSON 카드 정의와 시전 경로로 사용 가능하며 덱 빌딩에는 나오지 않는다.
