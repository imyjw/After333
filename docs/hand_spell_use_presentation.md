# 손패 스펠 공통 사용 연출

2026-10-24 사용자 요청. 대환단·마정석·보조배터리처럼 별도 타일을 지정하지 않고 위로 드래그하는 마법은 카드마다 다른 효과 대신 같은 푸른 조각 연출을 사용한다. 기존 전체 전장 마법·지속 자원 마법도 `TryCastPlayerPersistentSpell` 경로를 사용하면 함께 적용된다. 2026-10-25부터 트랩 5종도 위로 드래그해 설치하고 같은 연출을 사용한다. 타일 지정 마법·유닛/건물 소환·로봇 합체 재료 선택은 이 경로에 포함되지 않는다.

- 사용한 카드 그림이 잠깐 푸르게 반짝인 뒤 작은 푸른 조각으로 분해되어 바깥쪽·위쪽으로 흩어진다. 청백색 반짝임을 더하고 **0.145초**에 종료한다. 카드별 색·모양 구분이나 새 효과음은 추가하지 않는다.
- 실제 사용 요청 직전 그림의 스프라이트·UV·색·실제 종횡비 영역·위치·회전·배율·Canvas 순서를 저장한다. 응답을 기다리는 동안 놓은 위치에 정지된 시각 사본을 유지하고, 원래 RuntimeId의 손패 그림·입력은 숨겨 손패로 돌아가지 않게 한다. 드래그 위치와 슬롯 재사용/정렬을 분리하며 요청이 실패하면 정상 표시·입력으로 복구한다.
- 로컬은 공유 게이트웨이의 성공한 명령 직후, 온라인은 투영된 자기 `SpellCast` 또는 트랩 설치의 자기 `TrapInstalled` 확정 이벤트를 받는 즉시 분해 연출을 시작한다. 지진 등 전장 이펙트 종료나 손패 화면 갱신은 기다리지 않는다. 스펠 서버 이벤트에 손패 RuntimeId가 없으므로 같은 CardId의 미확정 요청 중 가장 오래된 것을 연결한다. 트랩 설치 응답은 설치한 본인에게도 CardId·RuntimeId 없는 일반 응답이므로 클라이언트의 미확정 트랩 요청만 제출 순서대로 연결한다. 일반 마법 대기는 소비하지 않고, 상대 설치 응답도 자기 연출을 확정하지 않는다. 이후 정확한 RuntimeId가 손패에서 제거될 때까지 원본 표시 억제를 유지하고, 지연된 갱신으로 연출을 재시작하지 않는다. 동명 다른 사본·옛 상태 재표시·확정 없는 스냅샷은 새 연출을 만들지 않는다.
- 비용 부족·명령 송신 실패·서버 `command_rejected`는 미확정 캡처를 폐기한다. 재접속/전투 연출 취소·Disable/Destroy·튜토리얼 초기화는 대기 캡처와 재생 중 연출을 모두 정리한다. 장면 종료 후 남기거나 과거 연출을 재접속 시 복구하지 않는다.
- 기존 전투 판정·자원 차감·네트워크 이벤트/DTO·상대 카드 공개·상대 숨겨진 손패는 그대로다. 연출은 입력/전투 연출 대기열에 새 대기 시간을 추가하지 않고, `unscaledTime`으로 일시정지 중에도 끝난다. 전체 전장 마법의 기존 상태 표시 지연은 유지한다.
- 임시 복제 사본도 정상 사용하면 이 푸른 연출을 사용한다. 사용하지 않은 임시 사본의 턴 종료 소멸은 기존 **회색** 연출을 유지한다.

실기기·실서버 통신·클라이언트 빌드/설치·서버 배포·DB 변경은 수행하지 않았다. 업데이트한 사용자 빌드에 포함되며 서버 재배포는 필요 없다.
