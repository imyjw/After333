# 공통 공격력·최대 체력 증가 연출

2026-10-26 사용자 결정. 대환단 전용 발밑 파동·상승 기운을 모든 소환물에 사용할 수 있는 공통 연출로 확장했다. 현재 게임 판정·카드 수치·서버/DB는 변경하지 않는다.

## 표시 규칙

| 같은 화면 갱신에서 해당 대상에게 실제로 증가한 전투 수치 | 색 |
|---|---|
| 공격력만 증가 | 빨강 |
| 최대 체력만 증가 | 초록 |
| 공격력과 최대 체력 모두 증가 | 노랑 |

기존 두 단계 도형·0.62초 재생·반투명도는 유지하고 색상만 달리한다. 발밑 원형 파동이 퍼진 뒤 몸 둘레로 기운이 솟아올라 사라진다. 새 스프라이트 시트가 아니라 기존 uGUI 메시 방식이다. 마스터·일반 유닛·건물과 양쪽 플레이어에 적용하며, 여러 대상의 증가는 각각 동시에 재생한다.

대환단은 자기 마스터의 공격력을 올리므로 빨강이다. 기본 증가량30, 강화 단계별 증가량은 기존 `DaehwandanCardRules`를 그대로 따른다. 손패에서 사용한 카드가 푸른 조각으로 분해되는 **0.145초 공통 사용 연출**도 유지한다.

사용자가 예시로 든 단일 공격력+10, 아군 전체 최대 체력+10, 단일 공격력/최대 체력+5 효과는 각각 빨강·대상별 초록·노랑을 사용하게 된다. 이 작업에서 그 예시 카드 자체를 새로 등록하거나 효과를 구현하지는 않았다.

## 증가 감지와 신원

- `BattleScreenPresenter.Present`가 로컬 공유 규칙/온라인 투영 상태를 보드에 반영한 직후 공통 연출에 전달한다. 카드 이름을 나열하거나 대환단의 `SpellCast` 이벤트만 보고 증가를 추측하지 않는다. 미래의 강화 효과도 확정된 전투 상태의 수치를 실제로 올리면 이 경로를 재사용한다.
- `(OwnerId, RuntimeId)`별로 이전 `BaseAttack`·`MaxHp`의 정수값을 저장해 다음 표시 상태와 비교한다. 로컬 상태가 같은 객체를 직접 수정해도 이전 수치는 유지된다. 온라인은 새로 생성된 투영 객체끼리도 비교한다.
- `CurrentHp` 회복/피해는 최대 체력 증가가 아니다. 광폭의 잃은 체력, 늑대 무리 수, 개방 방주의 보유 골드 등으로 계산되는 조건부 공격력 변화도 이 강화 연출의 대상에 포함하지 않는다. 실제 전투 공격력 속성인 `BaseAttack`과 `MaxHp` 증가를 관찰한다.
- 첫 화면·재접속 첫 상태·새로 소환된 RuntimeId·정의가 바뀐 변신은 기준값만 저장하며 과거 강화나 원래 스탯을 새 증가로 재생하지 않는다. 감소·동일 상태 반복·빈 이벤트에도 새 연출을 만들지 않는다. 비교는 화면 상태 갱신 때만 하며 매 프레임 전투 상태 전체를 검사하지 않는다.
- 연출 중 이동/자리 교환은 같은 RuntimeId의 현재 타일을 찾는다. 대상 사망·교체·사라짐·비활성화 때는 정리하며 다른 유닛으로 연출을 옮기지 않는다. 오버레이는 재사용한다.
- `unscaledTime`으로 진행하고 입력을 받지 않으며 기존 `IsBusy`/전투 이벤트 대기 시간에 추가 지연을 넣지 않는다. 그리기 순서260은 스탯창4950과 기존 손패·미리보기보다 아래다. 몸체의 실제 스프라이트 영역을 사용한다.
- 전투 연출 취소/새 연결·재접속 준비/튜토리얼 재시작·비활성화/파괴 때 연출과 비교 기준을 함께 초기화한다. 새 상태를 기다리는 동안 옛 연출을 복구하지 않는다.

## 검증·반영 범위

격리 Unity6000.3.12f1의 D3D11 배치 검사 **68/68 통과**. 공통 연출8개(기존 대환단3개 이관+신규5개), 기존 스펠10·손패 드로우10·임시 복제8·드래그10·무피해 반격3·이동교환5·내 덱10·상대 덱2·상대 손패2를 포함한다. 세 색의 실제 렌더 픽셀, 유닛/건물/마스터·양쪽, 광역5대상, 회복/조건부 공격력/초기·재접속 제외, 새 온라인 투영 객체, 반복 표시 미재생, 이동·교환 추적, 사망/비활성화/실시간 만료를 검사했다. 원래 native LevelPlay 제외는 SDK 없는 검증 사본에만 적용했다. 전체 프로젝트/실광고 검사 성공을 의미하지 않는다.

테스트 캡처는 검증 프로젝트의 `Captures/StatIncrease_20261026` 아래에 세 색의 단계별 PNG와 비교 스트립으로 저장한다. 기존 사용자 Editor/씬·애니메이션 자산을 저장하거나 재생하지 않았다. 클라이언트는 사용자가 재빌드·설치해야 휴대폰에 반영된다. 이 변경에 서버 재배포나 DB 마이그레이션은 필요 없다. 실제 휴대폰·운영 전투/통신 검증은 별도다.
