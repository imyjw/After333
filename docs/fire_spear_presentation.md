# 파이어스피어 카드와 관통 연출

2026-10-01. 사용자 스펙과 기존 전장별 열·관통 좌표를 사용한다.

파이어스피어(`FireSpear`)는 판타지 커먼 즉시 마법이며 마나 3을 소모한다. 살아 있는 내 소환물 또는 상대 소환물 하나를 선택해, 그 소환물이 속한 전장의 같은 열 앞·뒤 2칸에 각각 마법 피해 15를 준다. 유닛·건물·마스터 모두 대상이다. 빈 칸·봉인·은신한 적을 직접 선택할 수 없으며, 은신한 아군은 선택할 수 있다.

강화는 Lv.1부터 Lv.13까지 매 레벨 기본 피해 +1이다. Lv.13 기본 피해는 28이며 비용·범위는 바뀌지 않는다. 시전자의 현재 주문력을 피해 적용 전 한 번 읽어 각 대상에 더하고 마법 방어와 기존 상태 보호를 적용한다. 같은 열 반대 칸은 광역 피해이므로 은신 회피·쉴더 이전·비행 반감을 적용하지 않는다. 봉인·무적·불굴·방전·피해 후 파괴와 부활은 기존 규칙을 따른다. 두 직접 피해를 모두 처리한 뒤 파괴 연쇄와 마스터 패배를 판정한다.

정상 사용 시 비용과 선택한 손패를 한 번만 소비하고 카드는 버린 더미로 간다. 대상·턴·자원이 유효하지 않으면 자원·카드·전장을 변경하지 않는다. 덱 빌딩과 랜덤 보상에 포함하며 기존 커먼 확률·최대 3장 제한을 따른다.

- 네이티브 카드: `Assets/Project333/ScriptableObjects/StarterTen/Cards/FireSpear.asset`. `StarterTenCardCatalog`에 한 번 등록한다.
- 카드 그림: `Assets/Project333/Resources/Project333/CardArtwork/FireSpear.png`.
- 관통 VFX: `Assets/Project333/Resources/Project333/SpellEffects/FireSpear/FlameSpear.png`. 2048×1024 시트의 4×2 배열, 컷마다 512×512, 8컷이다. 프레임 순서는 윗줄 왼쪽에서 오른쪽, 이어 아랫줄이다.
- 생성 원본: `Tools/Art/Source/FireSpear/FlameSpear-Generated-20261001.png`. 첨부 원본은 참고만 했으며 보존했다.
- 정확한 생성 프롬프트: `Tools/Art/FireSpearPrompts.json`. 내장 `image_gen`을 사용했다.
- 안전한 패킹: `Tools/Art/PackFireSpearSprites.ps1`·`.cs`. 원본 셀 중심과 한 가지 배율을 유지한다. 칸 경계를 넘는 그림은 잘라내지 않고 실패 처리한다. 알파가 1 이상인 모든 픽셀 기준 최소 여백 23px, 알파 16 이상 기준 최소 여백 56px이며 카드 그림은 첫 컷 전체를 사용한다.
- 네이티브 가져오기: `Tools/Art/ImportFireSpearRegistration.cs`. SpriteEditor API, FullRect, Point, 무압축, mipmap 없음, 중심 pivot. 기존 PNG·카드 참조·GUID를 보존하고 재실행은 중복 등록하지 않는다.

그림을 교체할 때 `.meta`를 유지한다. 연출은 논리 타일 위치를 읽어 같은 열을 관통하고, 게이트웨이가 확정한 피해를 표시한다. 로컬·AI·온라인 성공 시전을 연결하고 실패·재접속 복원은 시전을 재생하지 않는다. 새 전용 음향을 추가하지 않으며 실제 피격에는 기존 공통 `UnitHit`를 사용한다.

## 재생과 입력

기존 연출의 1.5배속으로 8컷을 15fps로 재생한다. 시전 후 0.20초에 명중하며 게이트웨이가 확정한 실제 HP 감소와 공통 피격음을 표시하고, 약 0.333초 잔여 연출 뒤 끝난다. 정상 총 길이는 약 0.533초이다. 불꽃의 이동·프레임·페이드에 같은 배속을 적용한다. 실제 TileBackground 앵커의 Canvas를 우선 사용하고, 각 타일의 화면 좌표를 하나의 연출 좌표로 투영한다. 서로 다른 타일 root Canvas에도 동작하며 두 칸 앞에서 들어와 두 칸을 통과한 뒤 빠져나간다. 두 타일 범위의 RectMask2D로 다른 열 침범을 막고, 마스크 축은 양수로 유지한 채 투사체만 회전시켜 양방향 clipping 오류를 피한다. 전용 Canvas와 Image는 입력을 막지 않는다. 합법 타일의 기존 흰색 펄스 및 선택한 열의 대상 표시를 연결했다.

온라인은 명중·잔여 연출이 실제로 끝날 때까지 후속 메시지를 기다린다. 낮은 프레임률에서도 예상 시각만으로 다음 피해를 덮지 않는다. 현재 런타임 식별자와 연출 세대를 검사하며 전장 교체·비활성·종료에는 취소한다. 실패한 시전이나 재접속 상태 복원은 새 시전 연출을 만들지 않는다.

## 검증

- 최종 격리 Unity 6000.3.12f1: 관련 13개 fixture, **421/421 통과**, 실패·skip·누락·컴파일 오류 0. 신규 규칙 144, 네이티브 자산 6, 실제 연출 16, 기존 회귀 255개이다.

## 실제 전투씬 연출 재생 수정 — 2026-10-01

실제 Battle_VSlice에는 타일 배경 Canvas와 별도의 유닛 그림 Canvas가 있다. 유닛 그림용 작은 Canvas(빈 타일에서는 비활성)를 전체 화면 기준으로 선택하면서 메테오와 시한폭탄의 배치가 실패했고, 파이어스피어는 타일별 서로 다른 Canvas를 거부해 재생을 시작하지 못했다. 세 연출 모두 타일 배경 앵커의 Canvas를 우선 사용하도록 수정했다. 파이어스피어는 각 타일의 화면 좌표를 연출 Canvas로 투영해 선택한 소유자 전장의 두 타일을 관통하고 끝까지 빠져나간다. 왼쪽으로 이동할 때 180도 회전한 RectMask2D의 범위가 음수가 되어 화면에서 사라지는 추가 오류도 실제 픽셀 검사로 확인했다. 마스크는 양의 축을 유지하고 투사체만 회전하며 비행 좌표의 부호를 맞춰 양방향 재생을 복구했다. 시한폭탄은 활성화 뒤 표시 우선순위 4910을 다시 설정한다.

원본 실제 씬 회귀 6개 실패를 재현한 뒤 수정했다. 최종 격리 Unity 6000.3.12f1의 관련 12개 fixture **321/321 통과**, 실패·skip·누락·컴파일 오류 0. 실제 전투씬 공개 카드 사용·정확한 피해/자원/손패 1회 처리, 양쪽 시전자·대상 전장, 메테오 낙하/폭발, 시한폭탄 중앙 03→02→01→00와 상대 10타일 중심, 파이어스피어의 두 칸 관통·클릭 비차단·취소 및 기존 규칙/온라인 큐를 검증했다. 실제 씬 렌더 PNG 27장은 TempBuild/SpellPlaybackFix_20261001/Captures에 있다. 캡처는 독립 타일/유닛 Canvas를 유지하며 Overlay 출력만 별도 카메라에 연결한 검증 하네스다. 실기기·운영 온라인 경기 검증과 구분한다.

최종 입력 2088개의 소스/검사 사본 SHA가 일치하며 기존 카드 정의·PNG·음원·metadata·씬·Bootstrapper는 보존했다. 최초 실패와 중간 수정 실패도 별도 증거에 보존했다. 증거: TempBuild/SpellPlaybackFix_20261001/verification.json, unity-results.xml, baseline/, after-first-fixes/. 앱 빌드·설치나 서버 배포·재시작은 하지 않았다.
## 재생 속도 조정 — 2026-10-01

사용자 요청에 따라 FireSpearVfx.PlaybackSpeed를 1.5로 설정했다. 기존 10fps→15fps, 명중 0.30→0.20초, 잔여 0.50→약 0.333초, 페이드 0.20→약 0.133초, 정상 총 0.80→약 0.533초이다. 로컬·AI·온라인의 대기는 기존 공통 상수와 실제 잔여 시간에서 자동으로 같은 배속을 따른다.

격리 Unity 6000.3.12f1 기존 FireSpearPresentationTests 20/20 통과, 실패·skip·누락·컴파일 오류 0. 양방향 두 칸 관통, 프레임·명중 피해 표시, 렌더 지연 시 잔여 연출, 일시정지 및 로컬·AI·온라인 큐를 검사했다. 검사 입력 2100개 소스/사본 SHA 일치. 증거 TempBuild/FireSpearSpeed_20261001/unity-results.xml 및 verification.json. 소스 변경이며 사용자 앱 빌드·설치와 실기기 경기 검증은 수행하지 않았다.
