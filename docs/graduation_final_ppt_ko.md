### 4. 프로젝트 전체 시스템 구조 — `[1:00 ~ 1:35, 35초]`
- **화면 구성**: `system_architecture_diagram.png` 삽입
  - **Client**: `Unity 6000.3.12f1 (C# 9.0)`, Android/Windows, Google ID & Game ID 인증, `IBattleGateway` 패턴.
  - **Edge / Proxy**: `Cloudflare DNS (api.after333.com)` → `AWS Lightsail (서울 리전, Ubuntu 24.04)` → `Caddy 리버스 프록시` (자동 TLS, HTTPS / WSS 종단 후 `127.0.0.1:7333` 전달).
  - **Server**: `ASP.NET Core (.NET 8)` 서버 권위 아키텍처 — REST JSON(인증·단일 기기 로그인·드래프트·상점·강화·멱등 영수증) + WebSocket `/battle`(시청자별 비공개 정보 필터링, 20초 매칭 후 서버 AI 전환, 70초 재접속 유예, 결과 Outbox).
  - **DB & Backup**: `PostgreSQL 18` (`localhost:5432`, 순번 마이그레이션 `0001~0025`) + 매일 21시 암호화 `MYBOX` 자동 백업 및 격리 복원 검증.
- **발표 멘트**:
  > "프로젝트의 전체 시스템 구조입니다.
  > Unity 클라이언트는 Cloudflare DNS로 연결된 `api.after333.com` 도메인을 통해 서울 리전 AWS Lightsail 서버에 접속합니다.
  > 앞단의 Caddy 리버스 프록시가 자동 TLS 인증서와 HTTPS 및 WSS 웹소켓 연결을 종단하고, 내부 7333 포트의 ASP.NET Core .NET 8 서버로 전달합니다.
  > 서버는 계정·드래프트·상점·강화를 위한 REST API와 실시간 전투를 위한 WebSocket 세션을 모두 서버 권위 방식으로 처리하며, 상대 손패나 트랩 같은 비공개 정보는 서버에서 시청자별로 필터링합니다.
  > 모든 데이터는 PostgreSQL 18에 저장되며, 매일 밤 9시 암호화되어 네이버 MYBOX 클라우드로 자동 백업됩니다."
