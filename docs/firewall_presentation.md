# 파이어월 불꽃 벽 연출

2026-10-06 사용자 요청으로 불꽃 그림과 배치를 교체했다. 첨부한 세로 화염 기둥은 타일별 불꽃 모양·색감 참고용이다. 전투 규칙은 `battle_rules.md`의 Firewall을 따른다. 아래는 현재 연출이며 뒤의 날짜별 검증 절은 이전 작업 이력이다.

## 화면 동작

파이어월이 발동하는 다섯 타일 각각에 독립된 불꽃 벽 하나를 배치한다. 현재 전투 UI의 세로 다섯 타일을 따라 다섯 불꽃의 바닥이 한 줄로 정렬되고, 불꽃 끝과 불씨가 화면 위쪽으로 흐른다. 가로 불꽃 띠를 90도 회전하거나 다섯 타일 길이까지 늘리는 방식은 사용하지 않는다.

자기 전장·상대 전장과 앞줄·뒷줄, 전부 비어 있는 줄에도 표시한다. 한 장의 정사각형 스프라이트를 각 타일에 같은 비율로 표시하고 타일 하단 부근에 바닥을 맞춘다. 아래에 있는 불꽃이 앞에 그려져 자연스러운 겹침을 만든다. 화면 가장자리에서는 다섯 불꽃을 함께 같은 배율로 줄이며 그림 비율을 유지한다. 옆줄 중심을 가리지 않는다.

카드 사용 성공 직후 한 번, 기존 규칙의 다음 두 번의 글로벌 턴 시작에 각각 한 번 재생한다. 시전 직후에는 피해가 없으며 실제 피해는 기존 공유 전투 서비스가 처리한다. 16컷·12fps로 약 1.33초 타오르고 마지막 0.25초에 사라진다. 지속 시간 동안 항상 켜 두는 효과는 아니다.

타일별 기본 정사각형 표시 크기는 타일 폭·높이 중 작은 값의 1.35배다. 실제 보이는 불꽃 폭은 정사각형 셀보다 좁다. 화면 경계에 맞추는 제한도 가로·세로에 동일하게 적용한다. 불꽃의 화면 방향은 타일 연결선 방향에 따라 회전하지 않는다.

이미지를 교체할 때 `.meta`와 컷 순서·512px 규격·바닥 기준을 유지한다. 캐시 갱신을 위해 Play Mode를 재시작한다. 휴대폰 앱에는 사용자가 최신 클라이언트를 빌드·설치하여 적용한다.

## 전투 데이터와 재생 순서

로컬 인간/AI와 온라인의 실제 성공한 시전 및 AreaSpellEffectTriggered 이벤트 연결은 유지한다. 시한폭탄, 낙진·유지비, 파이어월·독가스 등의 기존 턴 시작 순서, 효과별 피해 숫자·공통 UnitHit·피격 및 사망 모션, 부활 대기를 바꾸지 않는다. 이번 작업은 그림과 타일별 UI 배치만 변경한다.

다섯 Image를 한 overlay 안에서 재사용하며 UI 클릭을 가로막지 않는다. 비활성화·취소·씬 종료 때 전체 효과를 숨기고 정리한다. 실제 재생 시작 이후 unscaled 경과 시간으로 프레임을 진행한다. 서로 다른 타일 root Canvas의 좌표를 같은 viewport로 변환하며 활성화 후 overrideSorting/4907을 다시 설정한다. 시전·기간·피해·비용·손패 드래그의 다섯 타일 강조는 기존 규칙을 유지한다. 상태 복원만으로 이펙트를 추측해 재생하지 않는다. 새 효과음은 추가하지 않았다.

기존 Inspector의 Firewall tile-effect 필드는 씬 직렬화 보존을 위해 남겨 두지만 현재 효과 크기를 조절하지 않는다. 현재 타일별 크기는 FirewallVfx의 1.35f 배율과 화면 제한, 프레임 속도는 FramesPerSecond에서 조절한다.
## 검증

## 실제 타일 Canvas와 드래그 범위 수정 — 2026-10-05

사용 시 불꽃이 보이지 않는 문제를 현재 `Battle_VSlice.unity`의 격리 복사본에서 재현했다. 실제 전투 타일은 각각 별도의 root Canvas를 사용하지만, 기존 `FirewallVfx.Play`는 선택한 다섯 타일의 root Canvas가 같아야 한다고 검사하여 재생 시간 0으로 종료했다. 위의 2026-09-30 검사는 단일 Canvas로 만든 연출 fixture였으므로 이 실제 씬 구조의 차이를 검증하지 못했다.

`FirewallVfx`가 첫 타일 배경 anchor의 전체 화면 Canvas를 overlay 기준으로 사용하고, 나머지 타일의 월드 좌표를 같은 overlay로 변환하도록 수정했다. 유닛 전용의 작은 sorting Canvas보다 타일 배경 Canvas를 우선한다. 실제 씬 RGB 검사에서 overlay의 최초 활성화가 표시 순서를 0으로 초기화하여 다른 타일에 가려지는 문제도 확인했다. 부모 지정·활성화 이후마다 overrideSorting과 기존 4907 순서를 설정하여 불꽃이 다섯 타일 위에 보이게 했다. 기존 불꽃 이미지·16컷/12fps·레이아웃·시전 및 다음 두 글로벌 턴 시작 연결·전투 판정은 유지한다.

`BattlePlayerInputController.HighlightDragHoverTarget`에 파이어월 전용 분기를 추가했다. 핸드의 카드를 타일 위에 드래그한 채 유지하면 선택한 행의 다섯 타일이 모두 기존 빨간 드래그 강조색으로 표시된다. 자기·상대 전장과 빈 행에 동일하게 적용하며, 다른 행으로 옮기거나 드래그를 종료하면 기존 범위 표시를 정리한다. 다른 광역 마법의 범위 처리는 유지한다.

격리 Unity 6000.3.12f1에서 관련 검사 92개가 최종 통과했다: 파이어월 연출 24개(별도 root Canvas 회귀 4개 및 최초 활성화/다른 행 재사용의 표시 순서 검사 포함), 파이어월 핸드 드래그 31개, 카드 사용 대상 점등 17개, 파이어스피어 연출 20개. 수정 전 드래그 검사에서는 다섯 칸 대신 한 칸만 강조되는 실패를 재현했다. 실제 전투 씬 복사본은 1920×1080·2340×1080·1280×720의 자기/상대 전장·앞/뒷줄 12사례에서 수정 전 재생 시간 0, 수정 후 1.33초 재생·프레임 진행·다섯 타일 범위·표시 순서·각 타일의 실제 불꽃 RGB 픽셀을 확인했다.
