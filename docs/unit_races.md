# 유닛 종족

최신 대조 기준: 2026-10-01. 현재 JSON 유닛 27종의 종족 표와 네이티브 카탈로그 내 유닛 25종을 구분한다. 네이티브 미등록 유닛은 현재 드래프트 Off인 마왕·용사이며, 종족 지정 자체는 그대로 유지한다. 아래 과거 날짜의 실행 검증 결과를 현재 카드 수로 고쳐 쓰지 않는다.

2026-09-21 사용자 지정 기준, 2026-09-30 오크 광전사·오크 족장·스켈레톤아처·엘프 장로 사용자 지정 추가, 2026-10-01 개방 방주 인간·마나 대포 종족 없음 추가. 현재 JSON 유닛 정의 27종.

- 종족은 특수효과와 별개인 유닛 전용 속성이다. 한 유닛에 여러 종족을 허용하며, 종족 없음은 빈 목록이다.
- 건물·마법·마스터에는 유닛 종족 항목을 설정하지 않는다.
- 망각·방전·봉인·스턴·빙결은 종족값 자체를 제거하지 않는다. 다만 봉인 중인 유닛은 기존 대상 지정 규칙에 따라 로봇 합체에서 제외한다.
- 로봇 특수효과와 카드 정의의 hasRobot 필드는 폐기했다. 로봇 합체는 살아 있는 아군 중 Robot 종족을 가진 유닛을 찾고, 로봇 공장은 Robot 종족이 포함된 드래프트 허용 유닛 정의를 찾는다.
- 합체는 재료의 종족을 전달하지 않으며 생존자의 종족을 유지한다. 종족 그 자체는 능력치를 변경하지 않는다.
- JSON은 유닛에만 races: ["Robot", "Human"]처럼 저장한다. 종족 없음은 races: []이다. Unity UnitCardDefinitionAsset의 Unit Races 배열도 같은 값으로 맞춘다.
- 새 유닛 추가 시 종족(없음 포함)을 사용자에게 확인하고, 기존 강화 규칙 확인 절차도 그대로 따른다. 이름·외형에서 임의 추론하지 않는다.

## 저장·검증

신규 전투 뷰와 서버 스냅샷은 Races 배열을 보존한다. 구버전 HasRobot은 오래된 전투 뷰/스냅샷 읽기에만 호환 필드로 남기며 신규 카드 정의에서는 허용하지 않는다. 명시적 Races 배열이 있으면 구버전 플래그보다 우선한다.

2026-09-21 검증 대상은 당시 실제 JSON 21종과 Unity 자산 19종 일치, 여러 종족·망각 유지, 로봇 합체·공장·AI 탐색, 전투 뷰와 서버 저장/복원. 클라이언트와 서버는 이 변경을 함께 업데이트해야 한다.

오크 광전사는 사용자 확인에 따라 `races: ["Orc"]`로 등록한다. 현재 JSON 유닛 27종과 새 네이티브 카드의 동일 종족값, 버서커와 분리된 종족 유지, 소환·전투 뷰/서버 저장·복원은 이번 등록의 검증 대상이며 아래 과거 실행 결과와 구분한다.

오크 족장의 오라 수신 자격은 같은 아군 전장의 Unit에 `Orc` 종족이 포함되는지로 판단하고 자기 자신도 포함한다. 종족은 오라·고유 특수효과 플래그와 별개이며 건물·마스터는 이 유닛 종족 오라의 수신 대상이 아니다. 상태 상호작용은 [전투 규칙](battle_rules.md)의 오크 족장 절을 따른다.

스켈레톤아처는 사용자 지정 `races: ["Undead"]`를 사용한다. 별도 특수효과가 없는 원거리 유닛이며 언데드 종족 자체에 새 능력을 추가하지 않는다. 이번 카드의 전투·전투 뷰/서버 저장·복원 검증 결과는 아래 과거 실행 기록과 별도로 기록한다.

엘프 장로의 CardId는 공백 없는 `ElfElder`이며 사용자 지정 `races: ["Elf"]`를 사용한다. 엘프 종족과 관통·속공은 별도 필드이고, 망각에도 종족은 유지한다. 이번 카드의 실행 검증 결과는 과거 기록과 별도로 기록한다.

개방 방주는 사용자 지정 `races: ["Human"]`를 사용한다. 현재 소유자의 골드에 따른 ATK는 카드별 효과이며 인간 종족 자체에 능력을 추가하지 않는다. 방전·망각·봉인에도 인간 종족값은 유지하고 골드 보너스만 기존 효과 억제 규칙을 따른다. [전투 규칙](battle_rules.md)의 개방 방주 절과 [강화 규칙](meta_rules.md)을 함께 확인한다.

마나 대포는 사용자가 확정한 종족 없음으로 `races: []`를 사용한다. 이름·대포 외형·원거리 Magic 공격에서 로봇 등 종족을 추론하지 않는다. 망각 중 공격 비용 효과가 억제되어도 빈 종족 목록은 유지한다. 새 native 카드의 빈 Unit Races·소환·전투 뷰·서버 복원은 이번 등록의 검증 대상이며 아래 과거 검사 통과 기록과 구분한다.
