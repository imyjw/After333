# 유닛 종족

2026-09-21 사용자 지정 기준.

- 종족은 특수효과와 별개인 유닛 전용 속성이다. 한 유닛에 여러 종족을 허용하며, 종족 없음은 빈 목록이다.
- 건물·마법·마스터에는 유닛 종족 항목을 설정하지 않는다.
- 망각·방전·봉인은 종족값 자체를 제거하지 않는다. 다만 봉인 중인 유닛은 기존 대상 지정 규칙에 따라 로봇 합체에서 제외한다.
- 로봇 특수효과와 카드 정의의 hasRobot 필드는 폐기했다. 로봇 합체는 살아 있는 아군 중 Robot 종족을 가진 유닛을 찾고, 로봇 공장은 Robot 종족이 포함된 드래프트 허용 유닛 정의를 찾는다.
- 합체는 재료의 종족을 전달하지 않으며 생존자의 종족을 유지한다. 종족 그 자체는 능력치를 변경하지 않는다.
- JSON은 유닛에만 races: ["Robot", "Human"]처럼 저장한다. 종족 없음은 races: []이다. Unity UnitCardDefinitionAsset의 Unit Races 배열도 같은 값으로 맞춘다.
- 새 유닛 추가 시 종족(없음 포함)을 사용자에게 확인하고, 기존 강화 규칙 확인 절차도 그대로 따른다. 이름·외형에서 임의 추론하지 않는다.

## 저장·검증

신규 전투 뷰와 서버 스냅샷은 Races 배열을 보존한다. 구버전 HasRobot은 오래된 전투 뷰/스냅샷 읽기에만 호환 필드로 남기며 신규 카드 정의에서는 허용하지 않는다. 명시적 Races 배열이 있으면 구버전 플래그보다 우선한다.

검증 대상: 실제 JSON 21종과 기존 Unity 자산 19종 일치, 여러 종족·망각 유지, 로봇 합체·공장·AI 탐색, 전투 뷰와 서버 저장/복원. 클라이언트와 서버는 이 변경을 함께 업데이트해야 한다.
