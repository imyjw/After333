## 공격·불 VFX

- 최소 0.32초 동안 Run으로 접근한다. 2026-09-28 사용자 요청으로, 가장 앞으로 나온 입과 대상 명중점 사이의 수평 여유를 표시 프레임 폭의 35%에서 15%로 줄였다. 기존보다 프레임 폭의 20%만큼 더 가까이 접근하며, 세로 위치·표시 배율은 유지한다.
- Attack 시작 후 약 0.167초에 불을 뿜는다. 불 VFX는 약 0.250초 동안 입과 실제 피격 대상의 명중점을 연결한다.
- 현재 불꽃 크기는 `RedDragonFireBreath.PlaceFlame`의 `sizeDelta`로 조절한다. 첫 값(길이)은 입→명중점 거리 ÷ (FlameOutlet−FlameInlet), 두 번째 값(두께)은 `Clamp(거리×0.9, 표시 프레임 폭×0.28, 표시 프레임 폭)×4.5`다. PNG의 512px 해상도를 화면 크기로 직접 사용하는 방식은 아니다. 2026-09-28의 1.5배 보정은 당시 설정이며 사용자가 이후 수정한 현재 수치는 위 코드가 기준이다. `Vector2 sizeDelta`에는 길이·두께 두 성분만 있다.
- 공격 프레임에 따라 입 위치를 추적한다. 대상 명중점은 다른 유닛과 같은 `GetVisualImpactWorldPosition()`을 사용하며, 공통 하향 10 UI 단위 보정을 유지한다.
- 공격과 반격은 별도 VFX 슬롯을 사용한다. 쉴더가 대신 맞는 경우 실제 피격 대상에 연결한다. 취소·씬 종료·소환물 교체 시 남은 연출을 정리한다.
- 공격자가 생존하면 최소 0.24초 동안 Run으로 복귀한다. 피해·반격·다중 타격 결과는 기존 전투 게이트웨이가 결정한다.

VFX 파일은 `Assets/Project333/Resources/Project333/Presentation/RedDragon/FireAtlas.png`다. 512px 셀 6개를 가로로 붙인 3072×512px 시트이며, 중앙 높이의 불 입구와 출구를 각각 약 0.04·0.94 위치로 연결한다. 캐릭터 스프라이트의 하단 16px 기준은 불 VFX 자체의 축에 적용하지 않는다.

현재 Attack 3·4·5컷의 입 좌표를 각각 추적하며, 입을 닫는 6컷 전에 불을 멈춘다. Attack 그림·속도를 크게 바꾸면 RedDragonPresentationAssets.GetMouthAnchor와 브레스 타이밍도 함께 조정한다.

Attack 그림에는 입의 불빛과 준비 동작을 넣고, 대상까지 뻗는 불은 별도 VFX로 표시한다. 카드 능력치나 기존 턴 종료 효과는 이 연출 작업의 변경 대상이 아니다.

## 소리

| 파일 | 길이 | 사용처 |
| --- | ---: | --- |
| `Assets/Project333/Resources/Project333/Audio/RedDragon/FireBreath.wav` | 0.460초 | 레드드래곤이 불을 뿜기 시작할 때 한 번 |
| `Assets/Project333/Resources/Project333/Audio/Common/UnitHit.wav` | 1.124초 | 모든 소환물·마스터의 공통 피격음 |

FireBreath는 직접 합성한 mono PCM16, 44.1kHz WAV다. 공통 UnitHit는 2026-09-28 사용자가 지정한 hits/55.flac을 stereo PCM16, 44.1kHz WAV로 무손실 변환한 파일로 교체했다. 원본 채널·음량·길이를 유지했고, 디코딩된 PCM 해시가 일치한다. 파이어브레스는 짧은 공기 분출과 낮은 불의 질감을, 공통 피격음은 사용자가 선택한 타격 녹음을 사용한다. 레드드래곤만의 별도 피격·사망음은 추가하지 않는다.

공통 피격음은 TileTextView.PlayDamageSound()에서 재생하며, 일반 피격 모션도 이 메서드를 함께 호출한다. 2026-09-28부터 공격을 시작한 소환물은 반격 피해를 받아도 공격 모션 뒤에 피격 모션을 붙이지 않는다. 공통 피격음·피해 표시·필요한 사망 모션은 유지한다. 이 규칙은 레드드래곤뿐 아니라 공통 공격 연출에 적용한다. 블루드래곤·광마의 기존 개별 피격음과 별도 VFX 명중음은 중복 재생하지 않는다. 같은 프레임의 광역 타격은 공통 소리를 한 번만 재생하고, 다음 프레임의 타격은 다시 재생할 수 있다. 피해 없이 파괴되는 경우에는 피격음을 추가하지 않는다. 기존 전체 음량·음소거를 따른다. 알파 16 이상인 원본 픽셀 2,356,943개가 포즈 추출 과정에서 누락·중복 없이 배정되었다. 알파 16 미만의 먼 배경 잔여물은 제거하고, 보이는 윤곽에 붙은 2px의 안티앨리어싱은 유지했다. 균일 배율의 nearest-neighbour 변환 뒤 30컷 모두 비영점 알파 기준 하단 16px, 보이는 알파 기준 18px 여백을 가진다. 같은 입력으로 다시 실행한 PNG 해시는 동일했다.

사용자가 수정한 블루드래곤·광마 PNG·클립·컨트롤러는 그대로 보존한다. 향후 아티스트가 레드드래곤을 수정한 뒤에는 과거 생성 원본으로 위 포장·임포트 도구를 다시 실행하지 않는다.

## 턴 종료 전장 화염 — 2026-10-07

사용자 요청에 따라 새 파이어월 그림으로 교체하기 직전에 사용하던 16컷 원본을 레드드래곤의 턴 종료 효과에 재사용한다. 원본 PNG 바이트를 그대로 복원하여 별도 리소스로 등록했다. 현재 파이어월의 새 그림과 일반 공격·반격의 파이어브레스, 카드 능력치는 유지한다.

효과가 실제 발동하면 상대 전장의 열 타일 각각에 독립된 불꽃을 표시한다. 빈 타일도 포함한다. 각 그림을 정사각형 비율로 배치하고 타일 하단에 바닥을 맞춰 화면 위로 타오르게 한다. 그림을 90도 회전하거나 전장 길이로 늘리지 않는다. 16컷·12fps로 약 1.33초 재생한다. 시작 약 0.25초 뒤 실제 결과에 따른 피해 숫자·공통 피격음·피격 모션을 표시하고 필요한 사망 모션을 이어서 재생한다. 부활 대기 중인 소환물을 일반 사망으로 처리하지 않으며, 재생 중 같은 타일의 소환물이 교체되면 이전 대상의 반응을 새 대상에게 전달하지 않는다.
