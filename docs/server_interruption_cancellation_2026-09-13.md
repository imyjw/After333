# 서버 중단 시 미완료 전투 취소 — 2026-09-13

## 확정 규칙

사용자 요청: 서버가 꺼지면 진행 중이던 전투는 없던 일로 취소하고 승패를 기록하지 않는다. PvP/PvE 모두 적용한다. 기존 런·덱·승패·티켓·재화는 유지한다. 새 런 생성이나 티켓 환급은 하지 않는다. 서버가 살아 있는 동안 개인 연결만 끊긴 경우의 기존 재접속 규칙은 유지한다.

## 구현

- 시작 시 이미 확정되어 디스크에 보관된 종료 결과를 먼저 DB에 반영한다. 반영하지 못하거나 손상된 결과 파일이 있으면 파일을 유지하고 서버 시작을 실패시켜 완료 경기의 결과를 잘못 취소하지 않도록 한다.
- 그 뒤 미완료 PvP 경기를 canceled/server_cancel로 처리하고 승자·참가자 결과 없이 접속·대기열·좌석 예약을 정리한다. 계정 런 성적과 지갑 등은 업데이트하지 않는다. 반복 실행해도 중복 처리가 없다. DB 스키마 변경은 없다.
- PvP 최신 스냅샷 복구 경로를 제거했다. 이전 경기 재접속이 새 매칭으로 바뀌지 않도록 거부한다. PvE는 기존 메모리 세션이 없으면 돌아갈 수 없으며 결과를 새로 만들지 않는다.
- 정상 서버 종료 중에도 진행 세션의 명령·AI·턴 제한·재접속 기권 실행을 차단한다. 이미 확정된 결과는 유지한다. 취소된 PvP에 뒤늦게 결과가 들어와도 성적이나 영수증을 만들지 않는다.
- Unity의 PvE 재접속 실패 → 로컬 패배 생성 경로를 제거했다. 전투가 없어졌다는 응답을 받으면 자동 재접속을 끝내고 결과 계산 없이 덱 화면으로 돌아간다. 기존 런·덱·성적을 보존하며 이전 결과 문구와 재접속 시작 예약만 비운다.
- 기존 서버 실행 명령의 startup recovery 스위치는 명령 호환을 위해 받아들이지만 전투 복원을 켜지 않는다. 취소 정책은 항상 적용된다. 스냅샷/명령 기록 자체와 보관 정책은 유지했다.
