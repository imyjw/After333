# PvE AI 고정 덱 10개

2026-09-09 전면 교체. 실행 데이터: `Server/Project333.PvpServer/Data/pve_ai_decks.json`.

## 구성 및 선택 규칙

- 최초 무작위 구성 후 사용자 요청으로 덱 1·2·3·7·8·9·10의 유니크 카드 구성을 조정했다.

- 기존 10개를 삭제하고 새 조합 10개로 대체했다. 덱 ID도 `pve-refresh-20260909-01`~`10`으로 구분한다.
- 덱 빌딩 사용 가능 카드 36종(includeInDraft 기본값 true)을 사용했다.
- 모든 덱은 전설 1장, 유니크 5장, 레어 9장, 언커먼 11장, 커먼 7장으로 총 33장이다.
- 동일 카드는 최대 3장이고, 10개 덱의 카드 구성은 서로 다르다. 전체 330장에 사용 가능 카드 36종이 모두 포함된다.
- 기존 방식대로 문명 구분 없이 희귀도별 무작위 조합을 생성한 뒤 고정했다. 제작 시드 20260909, Mulberry32 난수와 범위 밖 값 재추첨을 사용했다. 후보는 CardId 서수 순으로 정렬하고 전설/유니크/레어/언커먼/커먼 순으로 추출하며 3장에 도달한 카드는 해당 덱의 후보에서 제외한다.
- 새 온라인 PvE 전투마다 10개 중 하나를 동일한 10% 확률로 선택한다. 전투 시작 시 카드를 섞고, 진행 중인 전투에서는 재선택하지 않는다.
- AI 강화 레벨은 Lv.0이다. 플레이어 드래프트 확률, PvP 덱, 오프라인 데모 덱은 변경 대상이 아니다.
- 이 목록은 고정 조합이며 새 카드가 추가되어도 자동 변경되지 않는다. 희귀도나 등장 설정을 변경하면 목록을 다시 검토해야 한다.

## 적용 및 검증

- 유니크 카드 조정 후 재검증: 10개 덱의 구성·중복 제한·선택 및 합법적인 AI 행동 검사와 모의 전투 12회(판단 389회)를 통과했다. 불법 명령·원본 상태 변경 0건. 기록: TempBuild/AiDeckAdjust_20260909/ServerAiCheck.txt.

- 최초 교체 시 검증 완료: 새 덱 10개 모두 희귀도별 장수·중복 제한·사용 가능 카드·선택 인덱스·전투 시작·AI의 합법적인 첫 행동을 통과했다. 잘못된 입력 14개 거부와 PvP 덱 보존도 확인했다.
- 서버 빌드 오류 0개, 기존 경고 80개. 별도 모의 전투 12회(동시 작업 4개, AI 판단 453회)에서 불법 명령과 원본 상태 변경 0건.
- 검증 기록: TempBuild/AiDeckRefresh_20260909/ServerBuild.log 및 ServerAiCheck.txt. 실행 중인 서버는 재시작하지 않았다.

- 서버를 재빌드·재시작한 후 새 온라인 PvE 전투부터 적용된다. DB 마이그레이션은 필요 없다.
- `Project333.AiChecks`가 덱 수, 33장 합계, 희귀도별 장수, 카드 사용 가능 여부, 중복 제한, 실제 덱 선택 및 PvP 분리를 검증한다.
