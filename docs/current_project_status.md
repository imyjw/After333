## 운영 이전 결과 — 사용자 확인 기록

- 운영 주소: `https://api.after333.com`, 전투 `wss://api.after333.com/battle`. 서울 Lightsail → Caddy → `127.0.0.1:7333` ASP.NET8 → 로컬 PostgreSQL18. 현재 주 경로에 Cloudflare Tunnel은 없고 DNS는DNS only로 전환했다. `api-staging.after333.com`은 과거 시험 주소이며 운영 클라이언트 접속 주소로 사용하지 않는다.
- 운영 DB `project333_live`, 서버 계정 `after333`, DB 리슨 `localhost:5432`. 사용자가 제공한 전환 결과에서 migration24개/latest`0024_elf_elder_card_id`, 카드60종, 운영 Google client IDs2개와Desktop 교환/광고 콜백 구성을 확인했다. 이는 당시 검사이며 오늘 원격 재조회한 값은 아니다.
- 운영 전환 뒤 Android Google 로그인, AI 전투 결과 저장, 광고 완료 티켓+1은 사용자 확인. Android+Windows(GameID)의 사람 간PvP·결과 저장·재접속은 시험 서버에서 확인했다. 2026-10-19 Windows Unity Editor Play의 Google 로그인도 운영URL로 수정한 뒤 성공했다. 이를 standalone Windows 앱 시험이나 운영 전환 뒤 사람PvP 재시험으로 확대하지 않는다.
- 서버 시작은 수동 `systemctl`; `Restart=no`, 부팅 자동 시작 보류. 원래 노트북 서버는 중복 운영하지 않는다. 원복은 DNS만 되돌리는 방식이 아니며, 전환 후 생성된 DB와 미처리 결과 파일을 먼저 보존해야 한다.

## 백업·복원 확인 범위

- 매일 한국시간21시 Windows 작업 `After333-Encrypted-DB-Backup`이 Lightsail에서 새 `project333_live` 덤프를 생성·다운로드·age 암호화 후 MYBOX에 복사한다. 노트북 로그인/가동, MYBOX/N: 연결, SSH 허용이 필요하다. 예약 누락 시 가능한 시점에 시도하도록 설정했지만 종료 후 보충 실행을 실측한 기록은 없다.
- 2026-10-19 21:00 예약과 같은 시각대의 새 백업을 관측했다. RunId `20261019-120002-b49b6849`, 시작21:00:02.612, 완료21:00:22.255, Ready/결과0, 다운로드·전체 아카이브 읽기·암호화 왕복·드라이브 읽기·평문 제거 검증 성공. 매일 자동으로 웹 독립 다운로드까지 하는 것은 아니다.
- MYBOX에서 독립 다운로드한 2026-10-18 백업을2026-10-19에 신규 격리 DB/NOLOGIN 소유자로 실제 복원했다. public34테이블의 집합·열·건수·전체 내용 해시, 시퀀스·마이그레이션24개·제약·인덱스가 백업과 일치했다. 운영 DB와 게임 서버를 연결하지 않았고 시험 DB/역할을 제거했다.
- 서버 설정·검증 릴리스·PostgreSQL 설정·빈 outbox 디렉터리를 포함한57파일을 별도로 암호화 백업하고 MYBOX 웹 독립 다운로드 해시를 확인했다. 이 서버 파일 백업은 일일DB 작업에 자동 포함되지 않는다. DB와 outbox의 원자적 스냅샷이나 TLS 키·DB 역할 비밀번호·전체 호스트 복원을 검증한 것은 아니다.
- 복원 입력 평문은 확인된 원격2개·Windows1개 제거 완료. 원본 암호화 백업과 메타데이터·성공 증거는 보존했다. 전체 디스크의 평문 탐색이나 보안 삭제를 주장하지 않는다.
