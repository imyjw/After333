- 대상 없이 자신의 행동 턴에 사용한다. 카드는 즉시 버림패로 이동하고 전장 타일은 차지하지 않는다.
- 플레이어에게 귀속된 일시 주문력이다. 소환물의 활성 주문력과 합산하며, 소환물 사망·망각·방전·봉인으로 이 카드의 주문력이 사라지지 않는다.
- 모든 마법 피해에 적용한다. 마법 속성 일반 공격·반격, 유닛 효과, 마법 카드 피해에 피해 시점의 합계를 사용한다. 물리·고정 피해에는 적용하지 않는다.
- 소유자의 턴 종료 효과가 모두 처리될 때까지 유지한다. 레드 드래곤의 턴 종료 마법 피해도 증가한 뒤 만료된다. 다음 상대 턴 시작의 파이어월에는 이 카드의 보너스가 남지 않는다.
- 기존 PersistentEffectState로 시전마다 하나의 효과를 기록한다. 서버 저장/복원, 관전자별 상태 투영, AI 복제와 상태 키는 기존 경로를 사용한다. 만료된 효과는 주문력에 합산하지 않는다.
- 전투 HUD의 총 주문력에도 반영된다. AI는 공유 전투 시뮬레이션으로 증폭 후 마법 피해를 주는 수를 평가한다.
- 별도 카드 일러스트는 미등록. 기존 AI 고정 덱에도 추가하지 않았다.
