# After333 전투 모드와 AI 도전

사용자 확정: 2026-09-13. 이 문서는 기존 PVE/PVP 버튼의 모드 구분을 대체한다.

## 일반 전투

- 현재 런의 33장 덱으로 사람과 우선 매칭한다.
- 임시 대기시간은 서버 기준 20초다. 상대 사람의 입장 예약이 진행 중이면 그 참가가 우선한다.
- 사람 매칭이 성립하지 않으면 같은 대기 전투를 AI 상대와 시작한다. 클라이언트가 임의로 즉시 AI 상대를 선택할 수 없다.
- 사람 또는 AI와의 일반 전투 결과는 기존 33승/3패 런 성적과 런 종료 보상에 반영한다.
- 일반 전투에서 AI를 만나도 일일 AI 도전 횟수는 차감되지 않는다.
- 서버 설정 PROJECT333_MATCHMAKING_AI_WAIT_SECONDS로 대기시간을 변경할 수 있다. 현재 기본값 20초이며, 향후 30~40초로 늘리는 것은 후속 조정 사항이다.

## AI 도전

- 플레이어는 현재 진행 중인 런의 완성된 33장 덱을 사용한다. 일반 런 성적과 도전 결과는 별개다.
- 상대는 기존 10개 고정 AI 덱을 사용한다. 도전 상대 덱과 AI 난도 개선은 후속 작업이다.
- 계정마다 한국시간(KST, UTC+9) 날짜 기준 하루 3회 도전할 수 있다. 한국시간 자정에 새 날짜의 3회가 적용된다.
- 도전 버튼의 시작 요청을 서버가 수락할 때 1회 차감한다. 중복 클릭과 같은 요청 재시도는 같은 도전으로 처리하여 중복 차감하지 않는다.
- 승리 보상은 서버 골드(Resource Gold) 10, 패배 보상은 0이다. 무승부도 승리가 아니므로 승리 보상을 지급하지 않는다.
- 서버가 확정한 결과만 보상을 지급하며, 결과 기록과 골드·거래 기록은 하나의 트랜잭션으로 처리한다. 재전달로 두 번 지급하지 않는다.
- 도전의 승패는 일반 런의 승수·패수, 런 종료 조건, 런 종료 보상을 변경하지 않는다.
- 별도 티켓 비용은 없다. 현재 런을 시작할 때의 기존 티켓 비용은 기존 규칙을 따른다.
- 도전 시작 응답 후 앱이 닫혀도 서버에 남은 동일한 도전으로 입장하며 새 횟수를 차감하지 않는다.

## 재접속과 서버 취소

- 시작 화면과 덱 화면에서 '전투 재접속 (남은 시간)'으로 원래 전투를 이어간다.
- 서버는 전투 목적(run / ai_challenge)과 상대 종류(사람 / AI)를 구분한다. 사용자가 재접속 경로를 고를 필요가 없다.
- 연결 끊김을 감지한 뒤 60초 동안 기존 전투·좌석·덱·강화·전장으로 재접속한다. 기존 턴 시간과 AI 진행은 유지한다.
- 앱 종료 및 60초 재접속 만료에 의한 도전 패배는 횟수를 복구하지 않는다.
- 서버 장애·점검으로 미완료 전투가 취소되면 승패·보상을 기록하지 않는다. 취소된 AI 도전은 해당 도전을 차감했던 날짜의 횟수만 복구한다. 이전 날짜 도전의 취소가 새 날짜의 3회를 초과하는 횟수를 만들지 않는다.
- 서버 재시작 시 이미 확정되어 영속 결과 저널에 남은 결과를 먼저 처리하고, 나머지 미완료 도전만 취소·횟수 복구한다.

## API

- GET /ai-challenge/status: 일일 잔여 횟수, 다음 초기화 시각, 진행 대기 도전.
- POST /ai-challenge/start: RequestId, RunId, DeckId를 보내 도전 시작을 요청.
- GET /ai-challenge/attempts/{id}: 자기 도전의 확정 결과·지급 골드 조회.
- GET /battle/reconnect-status: 기존 전투 ID·남은 시간·상대 종류·전투 목적·도전 ID 조회.
- 기존 /pvp/reconnect-status는 구형 앱 호환을 위해 사람 전투만 반환한다.

## 구현·검증·배포 기록 (2026-09-13)

- 서버 통합 검사 114개와 실제 격리 서버 종료·재시작 검사가 통과했다. 20초 후 같은 대기방에서 AI 전투 시작, 사람 입장 예약 우선, 일반 런 성적 반영, 일일 제한·한국시간 자정 경계·중복 보상 방지·서버 취소 시 원래 날짜의 횟수 복구를 포함한다.
- AI로 전환된 대기방의 이전 참가자는 새 도전을 시작할 수 있으며, 실제 AI 전투 참가자는 연결 중과 60초 재접속 대기 중 모두 새 도전을 시작할 수 없다.
- 최초 도전 접속은 실제 전투 상태가 생긴 뒤에만 진행 중으로 기록한다. 시작 전 연결이 끊기면 같은 예약을 재사용하고, 시작 후 끊기면 기존 60초 재접속을 적용한다.
- Unity EditMode 검사 1,204개가 통과했다. 복제한 Unity 프로젝트에서 실제 시작·덱 씬을 렌더링해 공통 재접속 버튼, 예약 도전 이어하기, 전투·AI 도전 잔여 횟수 표시를 확인했다. 휴대폰 앱을 새로 빌드하거나 설치한 검증은 아니다.
- 운영 서버는 2026-09-13 19:10 KST에 `20260913-battle-modes-verified` 릴리스로 교체했다. 진행 중인 전투 0개를 확인하고 배포 직전 DB 백업을 생성했으며, 복원은 하지 않았다.
- DB 마이그레이션 0018·0019 적용, 기존 계정·런 성적·지갑·컬렉션·거래·요청 결과 기록의 동일성을 확인했다. 로컬·공개 주소의 상태, 새 API 인증 차단, 공개 WSS 연결도 통과했다.
- 사용하려면 최신 클라이언트를 사용자가 빌드·설치해야 한다. 이전 클라이언트의 즉시 PVE 시작 요청은 서버에서 차단한다.
