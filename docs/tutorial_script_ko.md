# After333 튜토리얼 대본

수정일: 2026-10-11. 사용자가 수정한 대본을 기준으로 4단계의 멀리건 실습과 5단계의 파이어볼 실습을 추가했다. 실습 단계의 입력 대상 강조와 희귀도 설명 통합을 반영했다. 골드 던전의 런당 3회 규칙을 반영했다. 그 외 대사와 진행 순서는 원문을 유지한다.

현재 구현은 도입과 **1. 게임에 대한 설명**, **2. 덱 빌딩**, **3. 게임 모드**, **4. 자원 시스템과 전투 1**, **5. 전투 2**까지 진행한다. 6단계는 후속 구현을 위한 대본이다. 2단계에서 완성한 덱을 유지하며 3단계로 이어지고, 튜토리얼 선택에서 3단계로 바로 들어오면 항상 같은 연습 덱 33장을 준비한다. 튜토리얼은 클라이언트의 연습 전용 상태에서 처리하며, 실제 계정·런·카드 강화·재화·도전 횟수와 분리한다. 실습은 지정한 행동이 실제로 완료되어야 다음 단계로 진행하고, 개방 방주와 대화창은 해당 행동의 대상과 버튼을 가리지 않도록 배치한다.

실습 안내: 플레이어가 실제로 클릭하거나 길게 눌러야 하는 동안에는 대화창의 ‘다음’ 버튼을 숨긴다. 해당 단계에서 눌러야 하는 실제 UI의 테두리에 초록색 오오라를 표시하며, 지정한 행동을 완료하면 강조를 해제하고 다음 설명으로 진행한다. 설명만 듣는 단계에서는 ‘다음’을 표시한다. 개방 방주가 남은 28장을 자동 선택하는 단계의 ‘계속’과 4단계 완료 후 ‘다시 배우기’는 유지한다.
