# 접히는 전투 손패

현재 동작: 2026-10-01 소스 기준. 아래 날짜별 검증 자료는 해당 변경 당시 기록이다.

- 기본 상태는 화면 중앙 하단의 축소된 부채꼴 손패다. 펼친 배치의 크기·간격을 0.48배로 하고 기준 위치에서 아래로 24만큼 내린다. 기존 SafeArea 하단을 기준으로 배치한다.
- 접힌 손패를 첫 클릭하면 전체가 펼쳐진다. 그 클릭은 카드 선택·사용으로 이어지지 않는다. 펼친 상태의 카드 클릭은 기존 카드 확대·선택이며 다시 누르면 선택을 해제한다.
- 내 타일과 상대 타일(양쪽 빈 타일 포함), 턴 종료 버튼, 톱니바퀴 버튼을 클릭하면 펼친 손패를 유지한다. 상대 타일은 2026-09-30 사용자 요청으로 예외에 추가했다. 누른 순간의 대상을 기억하므로 설정창이 열려 포인터 아래 UI가 바뀌어도 유지한다. 그 외 손패 바깥을 클릭하면 원래 타일/버튼 클릭 동작을 처리한 뒤 LateUpdate에서 손패를 접고 카드 선택을 해제한다. 손패 내부 클릭, 드래그, 스크롤성 포인터 이동은 바깥 클릭으로 오인하지 않는다. 접힌 손패에서 바로 드래그하면 손패만 펼치고 사용 명령은 보내지 않는다.
- 위치·회전·크기 전환은 기존 카드 시각 객체의 보간을 재사용하고 프레임 시간에 따른 지수 보간으로 변경했다. 드래그 시작의 크기와 회전도 부드럽게 변하며 위치는 포인터를 직접 따라간다.
- 턴 종료 후에도 손패를 펼치고 열람할 수 있다. 실제 사용·공격·이동·액티브의 기존 턴 잠금은 유지한다. 멀리건 교체 선택은 기존 중앙 화면을 사용한다.

조절 위치:
- `Assets/Project333/Runtime/Presentation/Hand/HandPresenterLayout.cs`: ApplyExpansion의 축소 비율/하단 위치.
- `HandPresenter.cs`: IsExpanded/SetExpanded와 기존 펼친 손패 설정.
- `HandCardTextView.cs`: 기존 _layoutLerpSpeed와 ApplyRuntimeAnimation.
- `BattlePlayerInputController.cs`: 첫 클릭·바깥 클릭 후 접기 처리.

## 사용 가능 타일 점멸 (2026-09-29)
- 펼친 손패에서 비용을 지불할 수 있는 카드를 선택하면 합법적인 사용 위치만 원래 타일색과 흰색 사이를 1.2초 주기로 부드럽게 왕복한다. 금으로 부족 자원을 대체하는 기존 비용 판정을 따른다.
- 유닛/건물은 내 빈 타일, 단일 대상 마법은 해당 마법의 합법 대상만 표시한다. 봉인·적 은신·종족/마스터 제한 등은 실제 타일 사용과 같은 CanCardUseOnTile 판정을 재사용한다. 파이어월은 양쪽 설치 가능 타일, 생화학폭탄은 상대의 설치 가능 타일을 표시하고 기존 드래그 시 4x2 범위 강조를 유지한다.
- 지진·메테오는 상대 전장의 빈 타일까지 포함한 10칸을 표시하고, 타일 클릭 또는 기존 위쪽 드래그로 사용한다. 파이어스피어는 실제 합법 대상이 있는 타일을 앵커로 선택해 해당 소유자의 같은 열 두 칸에 피해를 준다. 플라즈마 쉴드·마나쉴드는 양쪽 유닛·건물 중 마스터를 제외한 합법 대상만 표시한다.
- 트랩은 중복 설치 등 조건을 만족하면 내 마스터 타일을 무료 설치 앵커로 표시한다. 발동 시 자원 비용은 설치 비용과 별개다.
- 그 외 위로 드래그해서 사용하는 대상 미지정 마법은 존재하지 않는 클릭 대상을 만들어 표시하지 않는다. 현재 뉴클리어·시한폭탄은 대상 미지정 사용 경로이며 지진·메테오처럼 10칸 클릭 힌트를 추가한 상태가 아니다. 로봇 합체 발동 후의 로봇 선택 단계는 기존 적격 로봇 표시를 흰색 점멸로 보여준다.
- 카드 선택 해제·손패에서 제거·자원 부족·턴 종료 입력 잠금·상대 턴·행동 단계 종료 시 점멸을 해제한다. 잠금 중 손패 열람은 유지한다.
- TileTargetPulse는 원본 타일 스프라이트의 투명도와 모양을 따르는 흰색 UI 층이다. 원본 이미지·입력면을 변경하지 않으며 raycastTarget=false이다. 시간은 unscaledTime을 사용하고 매 프레임 대상 표시를 다시 계산해도 점멸 주기가 초기화되지 않는다.
- 조절: Runtime/Presentation/Battle/TileTargetPulse.cs의 주기 1.2초와 최대 불투명도 0.65(2026-09-30 사용자 요청으로 0.8에서 감소). 셰이더: Resources/Project333/TileTargetPulse.shader.
- 검증: 격리 Unity 컴파일 및 59/59 테스트 통과(신규 15 + 입력/온라인 게이트웨이 44). 실제 씬 타일 연결·투명도/입력 비차단·대상/비용/턴 조건·원래 색 복귀와 흰색 렌더 확인. 근거: TempBuild/CardTargetPulse_20260929/tests.xml 및 preview.png. 앱 빌드·실기기 검증은 하지 않았다.
