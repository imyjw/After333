## 임시 복제 손패 표시와 소멸 (2026-10-24)

- 실제 손패 인스턴스의 `IsTemporaryReplicate`가 true일 때만 카드 이미지 오른쪽 위에 작은 모래시계 아이콘을 표시한다. ‘이번 턴’ 글자 배지는 없으며 살아 있는 카드의 투명도·색감·사용 가능 초록 오오라는 바꾸지 않는다. 아이콘은 그림의 실제 종횡비 영역 안에 배치해 접힘·확대·드래그를 함께 따른다. 사용자가 제공한 황금 모래시계 PNG를 사용하며 입력을 가로채지 않는다. 원본 PNG 바이트는 보존하고 스프라이트 영역(250,108,715,1109; Unity 좌표)으로 바깥 투명 여백만 제외한다. - 카드 미리보기 아래에 제목 ‘임시 복제’, 설명 ‘사용하지 않으면 이번 턴 종료 시 손패에서 사라집니다.’를 표시한다. 이 상태에 한해 설명을 추가하는 사용자 요청이며, 다른 버프·디버프·적용 영향의 기존 이름/수치 중심 표시 규칙은 유지한다. 미리보기 그림에도 같은 모래시계가 붙고 일반 카드로 교체하면 둘 다 사라진다.
- 확정된 자기 턴 종료 후 실제로 손패에서 제거된 임시 사본만 **0.65초** 동안 가장자리부터 회색 입자로 흩어진다. 사본을 사용했을 때나 일반 카드가 제거됐을 때에는 재생하지 않는다. 슬롯 인덱스나 CardId만으로 판단하지 않고 RuntimeId로 구분한다.

- 연출은 슬롯 재사용/재정렬과 분리한 시각 사본으로 화면 위치를 고정한다. 게임 판정·입력·상태 적용을 기다리게 하지 않으며 unscaledTime으로 일시정지 중에도 끝난다. 카드당 메시216칸·회색 입자최대72개로 제한하고, Disable/씬 종료 시 정리한다. 실제 유닛·카드 데이터·복제 판정과 서버/DB는 변경하지 않는다.
