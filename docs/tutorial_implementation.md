## 실행 경계와 반복

`Tutorial_VSlice` 자체는 로그인·서버·실제 티켓/재화 없이 로컬로 동작한다. 다만 2026-10-22 요청에 따라 게임 시작 씬의 로그인 창이 표시된 동안에는 튜토리얼 진입 버튼도 배경 뒤로 가려지고 터치가 차단된다. 기존 실제 씬 UI를 빌려 개방 방주와 대화창을 덧씌우고, `TutorialRuntimeIsolation`과 연습 모델로 계정 새로고침·구매·광고 초기화·영수증 복구를 우회한다. 전투는 `LocalBattleGateway`/공유 규칙으로 처리한다. 일반 서버AI 대신 대본의 정해진 소환/공격/턴 종료만 수행한다.

필수 행동 단계는 Next를 숨기고 실제 대상의 테두리를 초록색으로 강조한다. 잘못된 대상·취소된 길게 누르기·완료되지 않은 뒤집기 등은 진행시키지 않는다. 선택 모달이 열리면 완료 처리를 유예하고, 다시 시작/주제 선택은 정해진 연습 상태를 복원한다. 스킵은 실제 런이나 계정에 저장하지 않고 시작 화면으로 돌아간다.

시작 손패5장은 Goblin/ManaPond/firebolt/ManaShield/PlasmaShield이며 실습에서는 firebolt를 SkeletonArcher로 교환한다. 첫 기본 드로우는PowerPlant, 다음 자기 턴은firebolt다. 마스터의 골드3/4는 멀리건 전 배정한다. 연습 추가 자원은 마나3+골드5; 고블린은마나2, 샘은남은마나1+골드5로 낸다. 이 연습용 초기화는 실제 전투의 지급 규칙을 바꾸지 않는다.

## 대화 이전·다음 이동 (2026-10-24)

대화창의 ‘다음’ 왼쪽에 ‘이전’을 배치한다. 이미 표시된 대사만 한 단계씩 복습하며, 첫 대사에서는 비활성화한다. 복습 중 ‘다음’은 원래 대사로 되돌아오고, 현재 진행 위치에 도달한 뒤에만 새 단계를 진행한다. 완료된 카드 선택·티켓 사용·소환·자원 지급·강화를 다시 실행하거나 이전 씬을 다시 불러오지 않는다.

복습 동안 실습 입력과 현재 단계의 초록 포커스를 잠시 중지한다. 미완료 실습 대사에 돌아오면 ‘다음’을 다시 숨기고 실제 대상 강조를 복구하므로 실습을 건너뛸 수 없다. 씬 로딩·전투 효과 처리·강화표 뒤집기 중에는 대화 이동을 잠근다. 주제 선택/다시 시작은 복습 이력도 새로 시작한다. 1단계 자원/골드/카드 종류 시각 자료와 금화 눈은 표시 중인 대사를 따른다. 좁은 전투 패널에서는 버튼을 아래쪽 한 줄에 배치하며 실습 동작 안내는 ‘다음’ 자리를 사용한다.

대화 이력과 배치는 `TutorialSceneController.Navigation.cs`가 담당하며 `TutorialSession`의 실제 진행 상태와 분리한다. 격리 Unity6000.3.12f1에서 기존 관련 검사와 추가 대화 이동 회귀 **74/74 통과**(11개 새 사례 포함). EditMode의 실제 씬/컴포넌트·입력 호출 검사이며 휴대폰 터치·앱 빌드는 별도다.

## 무엇을 수정할지

- 대사와 단계 정의: `Assets/Project333/Runtime/Application/Tutorial/TutorialSession.cs`. 주제별 `FirstChapterStep` 등 실제 정의를 확인하고, 문서 대본과 함께 수정한다.
- 행동 완료 판정/배치: `Assets/Project333/Runtime/Presentation/Tutorial/TutorialSceneController*.cs`와 해당 practice 모델. 대사만 바꿔도 실습 종류·완료 조건이 자동 생성되지는 않는다.
- 카드 강화 연습: `TutorialUpgradePractice.cs`. 실제 계정의 골드·카드/레벨이나 카드 자산을 변경하지 않는다.
- 개방 방주 Idle: 사용자가 교체한 `Assets/Unit/GaebangChief/Idle.png`와 현재 네이티브 클립/컨트롤러를 따른다. 금화 눈 대사에서는 정지 이미지로 전환하고 대사가 끝나면 Idle로 돌아간다.
- 실제 게임 UI/미리보기/전투 기록 형식을 재사용한다. 툴팁은 초록색 포커스 위로 표시하고 빨간 활 등 문양의 실제 이미지 영역을 강조한다. 가이드/대화창이 실습 버튼을 가리지 않도록 한다.
