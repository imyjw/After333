이 문서는 현재 구현된 카드와 아직 기획에만 남아 있는 카드를 한곳에서 확인하기 위한 목록이다.

- 최종 갱신일: 2026-09-04
- 실제 카드 데이터 기준: `Assets/Project333/Resources/Project333/Data/cards.json`
- 현재 실제 등록 카드: 41장
- 마스터는 덱에 들어가는 카드가 아니라 전투 기본 소환물이므로 아래 41장에 포함하지 않는다.
- 카드 문구와 실제 코드가 다르면 `cards.json`, 전투 규칙 문서, 전투 코드 순서로 다시 점검한다.

## 1. 표 읽는 법

비용 표기:

- `마나`, `기`, `전력`, `골드`를 그대로 적는다.
- 비용이 여러 종류라면 `마나 3 + 골드 3`처럼 적는다.
- 실제 비용 지불에서는 부족한 마나/기/전력을 골드가 1:1로 대신 낼 수 있다.

능력치 표기:

- `ATK / HP / 물리 DEF / 마법 DEF` 순서다.
- 현재 등록된 카드는 대부분 기본 물리/마법 방어력 `0 / 0`이며, 골렘은 `1 / 0`, 마왕은 `3 / 3`이다.
- 마법 카드는 전장 능력치가 없으므로 `-`로 표시한다.

강화 표기:

- `표준`: 최대 Lv.13. Lv.3, 6, 9, 13에는 ATK +1, 나머지 레벨에는 HP +1.
- `매 레벨 HP`: 최대 Lv.13. 모든 레벨에 HP +1.
- `매 레벨 피해`: 최대 Lv.13. 모든 레벨에 카드 피해 +1.
- `마왕 전용`: Lv.3, 6, 9에는 ATK +1, Lv.13에는 ATK +3, 나머지 레벨에는 HP +1.
- `용사 전용`: Lv.3, 6, 9에는 ATK +1, Lv.13에는 ATK +3, 나머지 레벨에는 HP +1.
- `불가`: 카드 강화 대상이 아니다.
- 다음 레벨 강화 비용은 `다음 레벨 x 3`장의 카드와 같은 수치의 Resource Gold다.

등장 표기:

- `드래프트`는 `includeInDraft`의 실제 값이다.
- `보상`은 서버의 최종 보상 풀 기준이다. `includeInRewards: true`여도 강화 불가능한 카드는 서버가 보상에서 제외한다.
- `Off` 카드는 기능이 구현되어 있어도 현재 일반 덱 빌딩이나 랜덤 보상에는 나오지 않는다.

## 8. 기획은 확정됐지만 현재 카드 DB에 없는 카드

현재 이 문서에 기록된 확정 카드 중 `cards.json`에 아직 등록되지 않은 카드는 없다.

## 9. 현재 데이터에서 확인된 정리 필요 항목

1. 케르베로스, 광마, 소림 1대 제자, 초소형 발전기의 `specialEffectText` 일부가 아직 영문이다. 기능에는 영향이 없지만 보유 카드 상세 문구를 완전히 한글화하려면 데이터와 Validator를 함께 정리해야 한다.
2. 천라지망, 대환단, 초소형 발전기는 `includeInRewards`를 생략해 원본 데이터상 기본값 `true`지만, 강화 불가능 카드라서 서버가 실제 랜덤 보상 풀에서는 제외한다. 데이터만 읽을 때 혼동되지 않도록 나중에 `includeInRewards: false`를 명시하는 편이 명확하다.
3. 마나의 샘은 건물이지만 현재 `매 레벨 HP` 예외 목록에 없어서 표준 강화 규칙을 사용한다. Lv.3, 6, 9, 13의 ATK 보너스는 `canAttack: false`인 동안 실제 공격에는 쓰이지 않는다.
4. 로봇 공장은 `hasRobot: true`이면서 `includeInDraft: true`인 유닛만 생성한다. A-301이 드래프트 Off인 현재 상태에서는 A-111만 생성한다.
