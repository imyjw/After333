# After333 Card Catalog

이 문서는 현재 구현된 카드와 아직 기획에만 남아 있는 카드를 한곳에서 확인하기 위한 목록이다.

이름·비용·공격 속성·방어력·이동·모든 특수효과 설정·등장 여부·강화 규칙·원본 JSON까지 확인하려면 [카드별 전체 상세 명세](card_details.md)를 참고한다.

특수효과별 발동 조건·상태이상·상호작용·판정 예시는 [특수효과 상세 명세](special_effects.md)를 참고한다.

- 최종 갱신일: 2026-10-20 (현재 JSON 60종·네이티브 카탈로그 54종·강화 코드·보상 필터 정적 대조)
- 최근 밸런스 반영: 오크 전사·오크 광전사 ATK 20, 마나 대포 ATK 40, 마나 위버 ATK 1, 광마 ATK/HP 30/60, 웨어울프 ATK 10, 골렘 물리 방어력 3, 블루 드래곤 마나 9, 레드 드래곤 마나 10. 각 카드 표는 강화 전 기본값이다.
- 실제 카드 데이터 기준: `Assets/Project333/Resources/Project333/Data/cards.json`
- 현재 JSON/domain 카드 정의: 60장. Unity `StarterTenCardCatalog`의 네이티브 카드 자산은 트랩 5종을 포함해 54종으로 별도 집계한다.
- 과거 대화 복원 기록에만 남은 미등록 카드 기획: 1종(Card Grader). 확인 가능한 전체 목록은 61종이다.
- 마스터는 덱에 들어가는 카드가 아니라 전투 기본 소환물이므로 아래 60장에 포함하지 않는다.
- 카드 문구와 실제 코드가 다르면 `cards.json`, 전투 규칙 문서, 전투 코드 순서로 다시 점검한다.

## 1. 표 읽는 법

비용 표기:

- `마나`, `기`, `전력`, `골드`를 그대로 적는다.
- 비용이 여러 종류라면 `마나 3 + 골드 3`처럼 적는다.
- 실제 비용 지불에서는 부족한 마나/기/전력을 골드가 1:1로 대신 낼 수 있다.

능력치 표기:

- `ATK / HP / 물리 DEF / 마법 DEF` 순서이며 Lv.0 기본값이다.
- 종족은 유닛에만 표시한다. `없음`은 종족 없는 유닛, `-`는 종족 항목이 없는 건물·마법이다. 복수 종족을 허용하며 망각으로 제거되지 않는다.
- 현재 등록된 카드는 대부분 기본 물리/마법 방어력 `0 / 0`이며, 골렘은 `3 / 0`, 마왕은 `3 / 3`이다.
- 마법 카드는 전장 능력치가 없으므로 `-`로 표시한다.

강화 표기:

- `표준`: 최대 Lv.13. Lv.3, 6, 9, 13에는 ATK +1, 나머지 레벨에는 HP +1.
- `매 레벨 HP`: 최대 Lv.13. 모든 레벨에 HP +1.
- `매 레벨 피해`: 최대 Lv.13. 모든 레벨에 카드 피해 +1.
- `방어 버프 마법`: 플라즈마 쉴드·마나쉴드는 강화 불가이며 각각 물리·마법 방어력 +10을 고정 부여한다. 덱 빌딩에는 포함하고 랜덤 카드 보상·카드팩에서는 제외한다.
- `마왕 전용`: Lv.3, 6, 9에는 ATK +1, Lv.13에는 ATK +3, 나머지 레벨에는 HP +1.
- `용사 전용`: Lv.3, 6, 9에는 ATK +1, Lv.13에는 ATK +3, 나머지 레벨에는 HP +1.
- `불가`: 카드 강화 대상이 아니다.
- 이 표의 강화 규칙은 기존 카드의 확정값이다. 새 카드에는 강화 가능 여부와 Lv.1~13 증가량을 사용자에게 별도로 확인한다.
- 목표 Lv.1/2/3/4/5 강화 비용은 동일 카드·계정 Resource Gold 각각 3/6/10/20/30, Lv.6~13은 각 33/33이다. [공통 비용표·서버 적용](meta_rules.md#card-upgrade-costs)를 따른다.

등장 표기:

- `드래프트`는 `includeInDraft`의 적용값이다. `includeInDraft`·`includeInRewards`를 JSON에서 생략하면 로더의 기본값은 `true`다.
- `보상`은 서버의 최종 보상 풀 기준이다. `includeInRewards: true`여도 강화 불가능한 카드는 원칙적으로 서버가 보상에서 제외한다. 사용자 확정 예외인 트랩: 리턴(`TrapReturn`)만 강화 불가 상태로 랜덤 보상에 포함한다.
- `Off` 카드는 기능이 구현되어 있어도 현재 일반 덱 빌딩이나 랜덤 보상에는 나오지 않는다.

## 9. 현재 데이터의 주의사항 및 확인 결과

1. 케르베로스, 광마, 소림 1대 제자, 초소형 발전기의 `specialEffectText` 일부가 아직 영문이다. 기능에는 영향이 없지만 보유 카드 상세 문구를 완전히 한글화하려면 데이터와 Validator를 함께 정리해야 한다.
2. `includeInRewards`의 적용값 On은 43종이지만 실제 랜덤 보상은 41종이다. 대환단은 2026-10-08 강화 가능으로 변경되어 보상·카드팩 풀에 포함된다. 천라지망, 초소형 발전기는 플래그를 생략해 기본값 `true`를 사용하지만 강화 불가이므로 서버가 제외한다. 트랩: 리턴만 사용자 지정 비강화 보상 예외이며, 트랩-미러 필드·트랩 - 반응 장갑·트랩 - 아이언 돔은 명시적으로 보상 Off다. 2026-10-03 플라즈마 쉴드·마나쉴드는 강화 불가·보상 Off로 변경했으며 덱 빌딩 On은 유지한다.
3. 트랩: 리턴은 사용자 확정 예외로 강화 불가여도 보상에 포함된다. 다른 강화 불가 카드의 보상 정책은 바뀌지 않는다. 설치 시 골드를 내지 않고 발동할 때 전투 골드 4를 지불한다.
4. 2026-09-12 확정: 케르베로스는 Lv.1~12 HP +1, Lv.13 ATK +1이며 최종 10/78이다. 마나의 샘은 Lv.1~13 모두 HP +1이며 최종 0/33이다.
5. 마나 위버의 현재 기본 ATK/HP는 1/10, 기존 강화 규칙을 적용한 Lv.13은 5/19다.
6. 로봇 공장은 `races`에 `Robot`이 포함되고 `includeInDraft: true`인 유닛만 생성한다. 현재 A-111, A-212, A-301을 생성할 수 있다.
