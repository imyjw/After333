# 내 덱에서 손패로 드로우 연출

2026-10-26 소스 기준. 전투 판정과 카드 드로우 수량은 변경하지 않는다.

- 내 카드가 실제로 드로우되면 오른쪽 아래 `PlayerDeck`의 맨 위 카드에서 출발해 뒷면을 보여주고, 뒤집히며 현재 손패 자리로 이동한다. 기본·추가 드로우와 로컬 튜토리얼/온라인 전투에서 같은 연출을 사용한다.
- 출발 위치·크기·회전·뒷면은 현재 `PlayerDeckPresenter.DrawSourceRect` / `DrawCardBackSprite`를 읽는다. 손패 Presenter가 유효한 전투 UI 배치에서 출발 좌표를 캐시하고 연속 드로우에도 재사용한다. 손패 갱신 및 진행 중인 비행에서는 가벼운 배치 정보 비교만 하고, 화면·안전 영역·Canvas·덱 배치·카메라 정보가 달라졌을 때만 출발 위치·크기·회전을 손패 Canvas 좌표로 다시 변환한다. 사용자가 편집한 덱 배치와 이미지가 반영되며 마지막 카드를 뽑아 덱 표시가 사라져도 같은 덱 레이어를 유지한다.
- 한 장의 비행 시간은 **0.38초**, 같은 묶음의 연속 드로우 출발 간격은 **0.07초**다. 이동 중 위로 약간 휘는 경로와 뒷면→앞면 뒤집기를 적용한다. 앞면의 공격력·체력·효과 수치도 함께 복사한다.
- 연출용 복사본은 클릭을 받지 않는다. 실제 손패 카드 객체는 원래 슬롯에 남고, 도착할 때까지 해당 `RuntimeId`만 숨기고 입력을 잠근다. 손패가 접히거나 펼쳐지거나 슬롯이 재사용되면 동일한 카드의 현재 자리로 도착한다. 연출을 마치거나 취소하면 원래 표시와 입력을 복구한다.
- 실제 드로우 이벤트와 새 손패 `RuntimeId`를 함께 확인한다. 단순한 화면 갱신, 상대 드로우, 임시 복제 생성, 최초 접속/재접속 손패에는 비행을 재생하지 않는다. 멀리건 교체는 기존 멀리건 연출이 담당하며, 일반 첫 턴 드로우는 멀리건 화면이 닫힐 때까지 대기한다.
- 일시정지와 무관한 `unscaledTime`을 사용한다. 전투 연출 취소·튜토리얼 재시작·비활성화·파괴 때 복사본과 숨김 상태를 정리한다. 카드 이미지/배치가 유효하지 않으면 연출을 생략하고 실제 카드 표시를 복구한다. 서버 행동 큐에 비행 시간을 추가하지 않는다.

## 출발점 좌표 갱신 수정 (2026-10-25 당시 이력; 현재는 아래 캐시 방식)

사용자가 서버 AI 전투의17·19턴에 왼쪽 아래에서 드로우되고21턴 이후 정상화되는 현상을 보고했다. 현장 영상/좌표 로그는 없으므로 그 전투의 정확한 트리거는 확정하지 않았다. 별도 Canvas 구조에서 손패 Canvas 배율을 바꾸자 기존의 고정된 local 출발점이 실제 덱과173.6px 어긋나는 재현 검사가 실패했다. 현재 덱 Transform에서 매 프레임 다시 변환하도록 수정한 뒤 통과했다. 마지막 카드가 숨겨져도 동일한 레이어 참조를 유지한다.

격리 Unity6000.3.12f1 관련 **78/78 통과**. 드로우9개에는 분리 Canvas 배율/출발점·덱 이동/마지막 카드 숨김·입력 복구,17·19·21턴의 온라인 이벤트→화면 갱신에서 일반 비행이 유지되고 멀리건 세션/시작·교체 비행은 시작하지 않는 검사가 포함된다. 이전 기본/추가 드로우·양 좌석·재접속·손패 재사용, 기존 멀리건·스펠·덱 검사를 함께 수행했다. 실제 휴대폰/당시 네트워크 세션 재현·클라이언트 빌드·서버 배포는 수행하지 않았다. SDK 없는 검증 사본에서 native LevelPlay는 제외했다.

## 출발 좌표 캐시 (2026-10-26)

- 고정된 전투 UI 배치에서는 한 번 구한 출발 Pose를 다음 드로우에도 공유한다. 시작/재접속 직후 배치가 아직 유효하지 않으면 이후 갱신에서 다시 준비한다. 비행하지 않는 동안 매 프레임 검사하는 별도 Update나 전역 이벤트 구독은 추가하지 않았다.
- 출발 덱/손패 부모의 변환 행렬·Rect, 스프라이트/비율 유지, Canvas 배율·픽셀 정렬·루트/렌더 모드/디스플레이, 화면 크기·안전 영역, 카메라/뷰·투영·뷰포트·대상 텍스처를 비교한다. 바뀌면 진행 중인 비행도 최신 출발점을 사용한다. 단순 색상 변화는 좌표를 다시 계산하지 않는다.
- 전투 연출 취소, 새 연결/재접속의 표시 초기화, 튜토리얼 재시작, 손패 비활성화/파괴, 덱 Presenter 교체 시 캐시를 비운다. `OnlineBattleConnectionTester.StopPresentationQueue → BattleBootstrapper.CancelCombatPresentation → HandPresenter.CancelCardDraws`의 기존 정리 경로를 사용한다. 재접속 손패를 과거 드로우로 재생하지 않는다.
- **도착점**은 접힘/펼침·손패 재정렬을 따라야 하므로 비행 프레임마다 갱신한다. 출발점에 대해서만 전체 좌표 변환을 생략하며0.38초/0.07초·뒤집기·입력 복구는 유지한다.
- 격리 Unity6000.3.12f1 관련 **83/83 통과**(캐시4·실제 Play 진입 손패10 및 기존 덱/멀리건/스펠/임시 복제/드래그). 고정 배치 조회100회에서 전체 출발 좌표 변환은 기존100회 대비 **1회**였다. FPS·기기 CPU 시간은 측정하지 않았으며 화면 변경은 테스트 내 실제 Canvas/카메라 배치 변화를 사용했다. 실기기 화면 회전/실제 재접속·앱 빌드·운영 서버 시험은 별도다. SDK 없는 검증 사본에서 LevelPlay를 제외했다.
