## 내 턴 배너 예외 복원 (2026-09-30)

사용자 요청으로 내 턴 표시는 안내창 공통 테마에서 제외했다. 기존 `YourTurnBanner.png`의 금색 픽셀 테두리·청록 장식·이미지에 포함된 내 턴 문구를 다시 사용하며 기본 표시 크기는 760×254다. 이미 테마가 적용된 배너에는 남아 있는 NoticeLabel과 공통 Outline을 숨기고 원본 크기·비율 표시를 복원한다. 배너의 위치, 페이드 0.15초/표시 1.4초/페이드 0.2초, 입력 비차단과 턴 전환 처리는 유지한다. 다른 안내창은 공통 테마를 유지한다.

검증: 격리 Unity 6000.3.12f1에서 기존 안내창 검사 11/11 통과. 배너 재사용·씬 위치·런타임 배치·입력 비차단 및 타이머·보상·매칭·설정의 공통 디자인 유지 확인. 실제 소스·검사·리소스 559개가 검사 입력과 일치한다. 원본 PNG·meta 및 전투 씬은 변경하지 않았다. 근거: `TempBuild/YourTurnBannerRestore_20260930/verified.xml`, `test-input-hashes.json`. 앱 빌드/설치·실기기 검증 없음. 클라이언트 새 빌드에 적용되며 서버 변경은 없다.

## 안내 문구·연결 진행 표시 정책

- 일반 안내에는 ‘온라인:’, ‘온라인 오류:’, ‘성공:’처럼 화면 경로를 표시하는 접두어를 붙이지 않고 전달된 본문을 표시한다. 사용자 지정 공격·이동·카드·턴 오류 문구는 로컬/서버의 실제 실패 원인에 대응한다. 예: ‘이 유닛은 이미 공격했습니다.’, ‘자원이 부족합니다.’.
- 최초 연결 중, 연결 완료 후 전투 복원 중, 전투 준비 완료의 일상적인 세 안내창은 띄우지 않는다. 개발용 상태 기록과 실제 연결 오류·매칭·재접속 안내는 별도 경로이며 필요한 안내는 계속 표시한다.
- 재접속 제한은 서버 감지 시점부터 70초다. 안내창 카운트다운은 서버가 준 남은 시간을 표시하며 문구를 고정 70으로 반복 초기화하지 않는다.
- 예전 접두어/메시지 조사인 [battle_notice_text_inventory_2026-09-26.md](battle_notice_text_inventory_2026-09-26.md)는 수정 전 목록으로 보존한다. 현재 표시 문구의 기준은 각 서비스와 `BattleBootstrapper.ShowOnlineToast`/`OnlineBattleConnectionTester`의 표시 경로다.
