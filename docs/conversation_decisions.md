# After333 — 이어서 작업할 때 보존할 결정

정리일: 2026-09-21. 이 대화에서 확인되는 사용자 결정과 기존 문서를 대조한 인수인계 색인이다. 전체 대화의 완전한 복제나 현재 운영 상태의 보증은 아니다. 새로운 사용자 지시가 우선한다.

## 작업 선호와 보류 사항 — 이어서 작업할 때 먼저 읽기

- **클라이언트 빌드·설치는 사용자가 한다.** 요청 없이 APK/PC 앱을 다시 만들거나 설치하지 않는다.
- **새 카드의 강화 규칙은 반드시 사용자에게 받는다.** 강화 가능 여부와 Lv.1–13별 수치/효과를 임의로 일반화하지 않는다. 이미 확정한 답은 다시 묻지 않는다.
- **서버 자동 실행은 보류다.** 매일 DB 자동 백업을 승인한 것을 게임 서버 자동 실행 승인으로 해석하지 않는다.
- **GitHub Actions 추가, 전투 기록 자동 정리는 보류다.** 기록 용량이 커진 것을 사용자가 알고도 당장은 유지하기로 했다.
- **지인 대상 비공개 테스트는 2026-09-23 이후**, 시작일은 미정이다. 날짜가 지났다고 자동으로 시작하지 않는다. 이 날짜는 위의 다른 보류 항목 재개일이 아니다.
- **구매·강화 복구는 앱이 자동 처리한다.** '이전 구매/강화 결과 확인' 버튼이나 '연결 복구 후 결과를 확인합니다' 안내를 추가하지 않는다. 완료/취소된 최종 상태만 표시한다.
- 검사 전에 **어떤 수정 때문에 무엇을 확인하는지** 짧게 설명한다. 이미 끝난 검사를 이유 없이 반복하거나 사용자가 직접 할 수 있는 단순 조작을 오래 대신하지 않는다. 필요한 회귀검사는 유지한다.
- 소스 수정, 서버 배포, 사용자 앱 설치를 구분해 보고한다. 서버 반영까지 요청된 작업에서 배포를 빼먹지 않되, 이전 배포 기록을 오늘의 실행 상태로 단정하지 않는다.
- 과거 테스트 계정의 승패·티켓, 연결된 기기, 로그인, 서버 PID 등은 당시 상태다. 새 작업에서 그대로 재사용할 사실이나 포괄적인 조작 승인으로 취급하지 않는다.
- 사용자는 새 대화 전환으로 기존 결정이 누락되는 것을 우려했다. **모든 과거 내용을 자동으로 기억한다고 보장하지 않는다.** 문서에서 확인되지 않으면 아래 경로로 필요한 부분만 찾아보고, 그래도 미정인 결정만 질문한다.
