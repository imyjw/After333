# After333 — 이어서 작업할 때 보존할 결정

현재 소스/우선순위는 [PROGRESS](../PROGRESS.md), 10-24 이후 최종 동작은 [최근 인계](antigravity_handoff.md)를 먼저 본다. 6단계 튜토리얼·Lightsail/백업의 날짜별 확인 범위는 [10-20 상태 기록](current_project_status.md)을 따른다. 아래 날짜별 결정은 변화 과정이므로 오래된 골드/드로우/멀리건/일일 도전 규칙을 최신 결정과 섞지 않는다.

최초 정리: 2026-09-21. 현재 결정 색인 점검: 2026-10-26. 이 대화에서 확인되는 사용자 결정과 기존 문서를 대조한 인수인계 색인이다. 전체 대화의 완전한 복제나 현재 운영 상태의 보증은 아니다. 새로운 사용자 지시가 우선한다.

## 작업 선호와 보류 사항 — 이어서 작업할 때 먼저 읽기

- **클라이언트 빌드·설치는 사용자가 한다.** 요청 없이 APK/PC 앱을 다시 만들거나 설치하지 않는다.
- **새 카드의 강화 규칙은 반드시 사용자에게 받는다.** 강화 가능 여부와 Lv.1–13별 수치/효과를 임의로 일반화하지 않는다. 이미 확정한 답은 다시 묻지 않는다.
- **서버 자동 실행은 보류다.** 매일 DB 자동 백업을 승인한 것을 게임 서버 자동 실행 승인으로 해석하지 않는다.
- **GitHub Actions 추가, 전투 기록 자동 정리는 보류다.** 기록 용량이 커진 것을 사용자가 알고도 당장은 유지하기로 했다.
- **지인 테스트의 최초 보류 기준은2026-09-23 이후였다.** 이후 사용자가 실제 지인PvP/CBT의 버그·밸런스 결과를 제공했다. 이를 새 테스터 초대·공개 배포·메시지 발송의 포괄적 승인으로 해석하지 않으며 다른 보류 항목은 별개다.
- **구매·강화 복구는 앱이 자동 처리한다.** '이전 구매/강화 결과 확인' 버튼이나 '연결 복구 후 결과를 확인합니다' 안내를 추가하지 않는다. 완료/취소된 최종 상태만 표시한다.
- 검사 전에 **어떤 수정 때문에 무엇을 확인하는지** 짧게 설명한다. 이미 끝난 검사를 이유 없이 반복하거나 사용자가 직접 할 수 있는 단순 조작을 오래 대신하지 않는다. 필요한 회귀검사는 유지한다.
- 소스 수정, 서버 배포, 사용자 앱 설치를 구분해 보고한다. 서버 반영까지 요청된 작업에서 배포를 빼먹지 않되, 이전 배포 기록을 오늘의 실행 상태로 단정하지 않는다.
- 과거 테스트 계정의 승패·티켓, 연결된 기기, 로그인, 서버 PID 등은 당시 상태다. 새 작업에서 그대로 재사용할 사실이나 포괄적인 조작 승인으로 취급하지 않는다.
- 사용자는 새 대화 전환으로 기존 결정이 누락되는 것을 우려했다. **모든 과거 내용을 자동으로 기억한다고 보장하지 않는다.** 문서에서 확인되지 않으면 아래 경로로 필요한 부분만 찾아보고, 그래도 미정인 결정만 질문한다.

사용자 요청으로 전투 기본 골드 지급량을 매 소유자 턴 시작 +1에서 +3으로 변경한다. 사용자 추가 지시로 선공 첫 Main 3골드와 후공 첫 Main 4골드를 모두 유지한다. 전투 턴 1에는 기본 지급 0, 전투 턴 2에는 예외 지급 +1, 전투 턴 3부터 소유자 턴 시작마다 +3이다. 로컬·AI·서버 공통 TurnStartService에 적용하며 자원 생산 카드, 계정 골드 및 기존 피해·파괴 우선 처리 규칙은 유지한다. 튜토리얼 대본의 기본 지급 설명과 실습 잔액도 변경한다.

## 2026-10-08 기본 골드 2·기본 드로우 2장

사용자 추가 요청으로 기본 골드 지급을 +3에서 +2로 변경하고 매 소유자 턴 기본 드로우를 1장에서 2장으로 늘린다. 선공 첫 Main 3골드와 후공 첫 Main 4골드 예외는 유지한다(전투 턴 1 지급 0, 턴 2 지급 +1, 턴 3 이후 +2). 기본 드로우 2장은 첫 턴에도 적용하며 시작 손패·멀리건 3장은 그대로다. 손패 초과 소각과 덱 소진 피해는 각 드로우 시도별로 기존 규칙대로 처리하고 첫 피해로 전투가 끝나면 두 번째 시도는 하지 않는다. 로컬·AI·서버 공유 서비스 적용, 계정 골드·자원 생산 카드 불변.

## 2026-10-08 최종 기본 골드 3·기본 드로우 1장

사용자 최종 확정: 선공 첫 Main 3골드, 후공 첫 Main 4골드 유지. 그 이후 모두 소유자 턴 시작 기본 골드 +3, 기본 드로우는 첫 턴 포함 매 턴 1장. 전투 턴 1 지급 0, 턴 2 지급 +1, 턴 3 이후 +3이며 시작 손패·멀리건 3장은 그대로다. 이 최종 결정이 같은 날의 이전 골드 +2·드로우 2장 결정을 대체한다. 현재 사용자가 수정한 공통 TurnStartService의 3·1 수치를 보존하고 문서·튜토리얼 대본·검증을 일치시킨다.
