# 액티브 특수효과

2026-09-21 확정.

- 소환물의 수동 발동 특수효과. 설명은 `액티브: 효과 내용`으로 작성한다.
- **기본적으로 자신의 턴에만 사용 가능하다.** 상대 턴에도 사용할 수 있다고 카드 설명에 명시한 경우에만 예외를 허용한다. 발전소에는 이 예외가 없다.
- 자신의 Main 단계에서 사용 가능한 소환물을 타일에서 클릭하면 타일 이미지 위에 작은 액티브 버튼이 뜬다. 버튼을 눌렀을 때만 사용한다.
- 턴·상태·사용 횟수 조건을 충족하면 비용 부족이어도 버튼을 표시하고 클릭 가능하게 유지한다. 비용 부족 상태에서 누르면 안내를 표시하며 자원·사용 횟수는 변하지 않는다. 발전소도 현재 공통 안내 문구인 "자원이 부족합니다."를 표시한다. 실제 비용은 골드 1이며 다른 자원으로 대체하지 않는다.
- 다른 타일/손패 선택, 사용 완료, 턴 종료, 망각·방전·봉인·스턴·빙결·사망 등 비용 외 조건으로 사용 불가가 되면 버튼을 숨긴다.
- 상대 소환물에는 버튼이 나타나지 않는다. 전투 연출·로봇 합체 선택 중에도 사용할 수 없다.

## 발전소 (PowerPlant)

사용자가 발전기라고 지칭한 기존 골드→전력 카드의 이름과 ID는 발전소/PowerPlant로 유지한다.

> 액티브: 1턴에 1번, 골드를 1 소모해서 전력을 2 얻는다.

- **소환한 턴부터 사용 가능**(사용자 확인).
- 발전소마다 내 턴에 1회. 일반 공격·이동 횟수는 소모하지 않는다.
- 정확히 골드 1을 소모해 전력 2를 얻는다. 부족한 골드를 다른 자원으로 대체하지 않는다.
- 기존 턴 시작 자동 교환은 삭제한다. 턴 시작 유지비 지불은 기존 전력/골드 규칙을 따르며, 그 이후 Main에서 액티브를 사용한다.
- 망각·방전·봉인·스턴·빙결·사망·상대 턴·전투 종료 시 사용 불가. 재접속은 사용 횟수를 초기화하지 않는다.
- 강화·기본 능력치·소환 비용은 변경하지 않았다.

## 구현·확장

공용 ActiveEffectService가 현재 지원하는 PowerPlant CardId의 실행 조건과 처리를 정의한다. 툴팁·클릭 UI·로컬 명령·서버 명령·AI는 이 규칙을 공유한다. 앞으로 다른 액티브 카드를 만들 때 효과 문구만 추가하지 말고 해당 카드의 조건/비용/효과/횟수 규칙을 확정해 핸들러와 회귀 검사를 추가한다.

ActivateEffectCommand는 타일 좌표와 소환물 RuntimeId만 전달한다. 서버가 소유권·현재 턴·상태·재료·사용 여부를 확인한다. LastActiveEffectTurnNumber는 전투 뷰, AI 복사/상태 키, 서버 스냅샷에 보존한다. 구버전 저장에는 -1(미사용)을 적용한다.

버튼은 실제 TileBackground RectTransform을 기준으로 배치하고 소환물보다 앞, 효과/미리보기보다 뒤에 렌더링한다. 런타임에 생성하므로 씬마다 수동 배선은 필요 없다.

## 검증·적용 상태

- Unity 6000.3.12f1 EditMode 최종 전체 1,253/1,253 통과. 실제 Battle_VSlice 복제 씬에서 타일 이미지 기준 버튼 배치·캔버스 정렬·클릭 후 전력 획득을 확인했다. 화면 픽셀이나 Android 실기기 터치 검증을 했다는 의미는 아니다.
- 소환 턴 사용, 발전소별 1회, 비용 부족/망각/방전/봉인/상대 턴 차단, 중복·오래된 RuntimeId 거부, 재접속 뷰와 AI 복사, AI 액티브→승리 마법 연계, 카드 설명/툴팁 검사 통과.
- 서버 빌드 오류 0개(nullable 경고 88개). 운영 DB 없이 실제 BattleSession 명령 처리, 양쪽 좌석, 중복 거부, JSON 저장·복원, 다음 턴 재사용 검사 통과.
- 증거: TempBuild/ActiveEffects_20260921/all-editmode-final.xml, server-active.log. 서버 검사: dotnet run --project Server/Project333.AiChecks/Project333.AiChecks.csproj -- --active-effects-only.
- 앱 빌드·설치와 운영 서버 재배포·재시작은 수행하지 않았다. 최신 클라이언트와 서버를 함께 업데이트해야 온라인에 적용된다.

### 비용 부족 버튼 동작 보완 (2026-09-21)

CanOfferActivation은 턴·상태·횟수 조건을 검사하고, CanActivate는 비용까지 검사한다. UI는 전자를 사용하고 AI는 후자를 사용한다. 버튼 클릭 시 현재 비용을 확인해 안내하며, 서버는 별도로 비용을 다시 검사한다. 골드 부족 후에도 버튼은 남고 골드 획득 후 재클릭할 수 있다.

이번 보완 검증: Unity 런타임·EditMode 테스트 어셈블리 분리 컴파일 성공, 서버 분리 빌드 및 양쪽 좌석의 비용 부족 거부·재시도·중복 거부·저장 복원 검사 통과. 이번에 추가한 Unity UI 테스트는 컴파일만 확인했으며 실행·실기기 화면 검증은 미수행. 앱 빌드·설치 및 서버 재배포·재시작 미수행.

- 2026-09-22 좌우 액티브 키워드 툴팁은 공통 안내인 “소환물의 액티브 버튼을 눌러 액티브 효과를 발동시킬 수 있다.”로 표시한다. 발전소 카드 자체 효과 문구와 비용·횟수 규칙은 유지한다.

## 2026-10-08 액티브 발동 전투 기록

- 로컬/튜토리얼 플레이어와 AI, 온라인 플레이어와 서버 AI 모두 액티브 발동 성공 시 소유자·소환물 이름·타일 좌표·효과 내용을 기록한다. 발전소 예: `플레이어의 발전소(0,0) 액티브 발동: 골드 1 소모, 전력 2 획득`.
- 자원 부족·상태 제한·오래된 RuntimeId·같은 턴 중복 사용으로 거부한 요청에는 성공 기록을 추가하지 않는다.
- 온라인은 서버가 `ActiveEffectActivated = 46` 기록을 생성한다. 기존 숫자 값은 유지하며 좌석 변환·JSON 저장·재접속 기록 경로를 재사용한다. 애니메이션 이벤트가 없는 액티브도 발동 및 실제 자원 증감을 기록한다.
- 관련 Unity EditMode 검사 60/60 통과. 실제 BattleSession의 양쪽 좌석 명령, 서버 AI 경로, 비용 부족·중복 거부, JSON 기록 저장 검사 통과. 서버/AiChecks 빌드 오류 0. 앱 빌드·설치 및 운영 서버 배포·재시작은 하지 않았다. 온라인 적용에는 최신 클라이언트와 서버가 필요하며 DB 마이그레이션은 필요 없다.
