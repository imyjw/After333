# 전투 유닛 이동 효과음

2026-10-23: 사용자가 첨부한 `move.mp3`를 내용 변경 없이 `Assets/Project333/Resources/Project333/Audio/Common/UnitMove.mp3`로 가져왔다.

- 온라인 일반 전투·골드 던전은 서버에서 승인된 `OccupantMoved` 이벤트를 받은 표시 경로에서 재생한다. 이동 요청을 보내기만 했거나 이동이 거절되면 재생하지 않는다.
- 양쪽 플레이어와 마스터의 실제 타일 이동에 적용한다. 위치 교환은 이동 이벤트가 두 개여도 수신 묶음당 한 번 재생한다. 이동 시각 애니메이션 설정을 꺼 두어도 효과음은 재생한다.
- 로컬·튜토리얼은 이동 명령 성공 직후 재생한다. 로컬 AI의 일반 표시 경로도 이동 성공 시 재생하고, 시각 애니메이션을 생략한 디버그 AI는 동기 실행 묶음 전후에 기존 유닛의 위치 변경이 확인되면 한 번 재생한다.
- 일반 상태 스냅샷, 소환, 제자리 이벤트, 좌표 없는 이벤트에는 재생하지 않는다. 공격을 위한 접근/복귀의 Run 애니메이션에 소리를 붙이지 않는다.
- `BattleScreenPresenter`의 기존 카드 드로우용 2D AudioSource를 재사용한다. 클립은 한 번 로드하며, 전체 음량은 기존 AudioListener 설정을 따른다. 배경음악 음량과는 독립적이다.

이동 소리는 공통 **효과음 볼륨**도 따른다. 최종 소리는 기존 개별 이동 음량 × 효과음 설정 × 마스터 음량이다. [오디오 설정](audio_settings.md)을 참고한다.

## 교체와 음량

- BattleScreenPresenter Inspector의 **Unit Movement Sound > Unit Move Volume**: 기본 `0.5`, `0`이면 음소거.
- **Unit Move Audio Clip**을 지정하면 그 클립을 사용한다. 비어 있으면 위 Resources 경로의 첨부 MP3를 자동 사용한다.
- 같은 MP3 파일을 교체할 때 `.meta`는 보존한다. 반복 재생은 하지 않는다.
- 클라이언트 표시 변경이다. 휴대폰에는 업데이트한 앱을 빌드·설치해야 하며, 서버 재배포나 DB 마이그레이션은 필요 없다.

## 확인

격리 Unity 6000.3.12f1에서 2개 검사가 통과했다. 실제 MP3의 AudioClip 임포트·길이·샘플·mono 설정을 확인하고, EnterPlayMode 검사에서 양쪽 승인 이동, 이동 시각 애니메이션 끔, 교환 묶음의 후속 중복 재생 방지, 로컬 이동·교환 성공, 로컬 이동 실패, 무관/잘못된 이벤트 무음, AudioSource 재사용 및 기존 전체 음량 보존을 확인했다. 실제 계정·서버 접속 없이 튜토리얼 격리와 메모리 로컬 전투를 사용했다. 물리 기기 청취 및 앱 빌드·설치는 수행하지 않았다.
