# 트랩 - 아이언 돔

2026-10-01 사용자 확정 카드. 최신 개별 판정은 [전투 규칙](battle_rules.md#irondome)을 따른다. 앱 빌드·설치 및 운영 서버 배포와 소스 등록을 구분한다.

## 카드 정의

| 항목 | 설정 |
|---|---|
| 이름 / CardId | 트랩 - 아이언 돔 / `IronDome` |
| 종류 / 소속 / 희귀도 | 마법 `TrapSpell` / 과학문명 `ScienceCivilization` / 레어 `Rare` |
| 설치 / 발동 비용 | 무료 설치 / 전력4, 부족한 전력은 전투 골드로 1:1 대체 |
| 강화 | 불가, Lv.1–13 증가량 없음 |
| 덱 빌딩 / 랜덤 보상 | 포함 / 제외 |
| 조건 / 효과 | `EnemyRangedUnitAttacksMaster`(4) / `DestroyAttacker`(3) |
| 피해 메타데이터 | `damage: 0`, `damageType: "None"`. 직접 파괴를 수치 피해로 계산하지 않음 |

문구: `트랩: 전력-4. 상대방 원거리 유닛이 내 마스터 공격 시, 그 공격을 취소하고 그 유닛을 파괴한다.(마스터 제외)`

설치는 자신의 Main 행동 턴에 살아 있는 내 마스터로 입력한다. 조건·효과·발동 비용·레벨·설치 순서를 설치 당시 포착하며, 설치할 때 발동 비용이 없어도 된다. 무료 설치 비용과 발동 전력4는 별개의 값이다. 동일 CardId가 이미 설치되어 있으면 자원·손패 변경 없이 거절한다. 다른 트랩은 함께 설치할 수 있다.

## 발동과 제외 대상

공격자와 대상의 합법성·명시 공격 비용 및 환술 최종 대상을 먼저 처리한다. 상대 일반 원거리 유닛의 실제 최종 대상이 설치자의 실제 마스터일 때만 검사한다. `AttackType.Ranged`가 기준이며 화면 거리, 비행 여부, 물리/마법 피해 종류는 조건이 아니다. 근거리 유닛·상대 마스터·건물 공격자나 내 일반 유닛/건물을 향한 공격에는 발동하지 않는다.

설치 순서대로 조건·비용을 확인하여 처음 둘 다 충족한 한 장만 발동한다. 전력+골드가 부족하거나 대상이 맞지 않으면 아이언 돔을 유지하고 다음 트랩을 검사한다. 비용·트랩 소모·정체 공개는 성공 발동 때만 한다. 다른 트랩도 발동하지 않으면 원래 공격은 정상 처리한다.

성공하면 공격 전체를 피해·쉴더 이전·연타·관통·반격 전에 취소하고 공격자를 직접 파괴한다. 공격자의 이미 승인된 공격 1회와 명시 공격 비용은 반환하지 않는다. 직접 파괴는 방어·주문력·무적·불굴 등을 계산하는 피해 패킷이 아니며 공통 파괴·오라 제거·연쇄 사망·유언·부활·승패 처리를 사용한다. 별도의 피해 수치·피격음이나 취소된 일반공격 타격을 만들지 않는다.

## 그림과 표시

카드 그림은 날아오는 미사일을 요격 미사일이 맞혀 공중 폭파하는 장면이다. 생성 프롬프트는 `Tools/Art/Source/IronDome/prompt.txt`, 실제 카드 그림은 `Assets/Project333/Resources/Project333/CardArtwork/IronDome.png`에 보관한다. 네이티브 카드 `Assets/Project333/ScriptableObjects/StarterTen/IronDome.asset`를 기존 카탈로그에 한 번 등록하고 그림은 Single·FullRect·Point로 연결한다. Unity의 네이티브 AssetDatabase/Sprite API로 metadata를 생성하며 기존 카드의 GUID·순서를 유지한다.

생성 그림은 투명 RGBA 1254×1254이며 전체 구도를 보존한다. 원본 Tools/Art/Source/IronDome/imagegen-IronDome.png와 실제 그림의 SHA256은 `74E0FCBB278D9673038BA3C0F76504E0911164347D1F6CF8E8089691192C31A6`다.

설치 때 상대에게는 기존 물음표 공통 카드와 “트랩”, 마스터 ?/Xn 개수만 표시한다. 성공 발동 시 양쪽 중앙에 실제 아이언 돔 카드를 공개한다. 발동한 플레이어의 실제 마스터에서 공격한 원거리 유닛까지 미사일이 0.5초 동안 직선으로 날아가고, 공격자의 위치에서 시한폭탄 폭발 16컷을 재생한다. 도착 후 폭발이 최대 크기로 커지는 4번 프레임에서 해당 공격자의 기존 Death 애니메이션을 시작한다. 취소된 일반 Attack·가짜 Hurt·피해 수치·피격음을 만들지 않는다. 부활 대기 상태라면 영구 사망으로 표현하지 않는다. 반응 장갑 전용 배리어는 재사용하지 않으며 새로운 음원을 추가하지 않는다.

연출은 확인된 발동 이벤트와 발동 전 스냅샷의 마스터·공격자 런타임 ID를 사용한다. 양쪽 소유자와 로컬/온라인 공통으로 적용하고, 온라인의 다음 상태 갱신은 미사일·폭발·사망 연출이 완료될 때까지 기다린다. 유닛 교체·취소·씬 비활성화 때는 연출을 정리하며 화면 코드에서 전투 상태를 변경하지 않는다. 재접속은 현재 포착 상태와 상대 개수만 복원하고 과거 발동·사망 연출을 재생하지 않는다.

미사일 PNG는 `Assets/Project333/Resources/Project333/Vfx/IronDome/Missile.png`이며 `IronDomeMissileVfx`에서 읽는다. 생성 원본·프롬프트는 `Tools/Art/Source/IronDomeVfx/`, 네이티브 등록 도구는 `Tools/Art/ImportIronDomeMissile.cs`다. 폭발은 `Project333/SpellEffects/TimedBomb/Explosion`을 그대로 재사용한다. 전력4 및 부족분 골드 대체 비용은 사용자 재확인에 따라 유지한다.

## 강화·보상·AI

강화 불가이므로 Lv.1–13의 증가량·강화 후 효과 수치가 없다. 덱 빌딩 후보에는 포함하며 기존 Rare 확률과 비레전더리 최대3장 규칙을 따른다. `includeInRewards: false`를 사용하고 트랩: 리턴의 비강화 보상 예외를 적용하지 않는다.

AI는 자신의 알려진 포착 조건·비용과 공개된 상대 일반 원거리 유닛의 적법한 마스터 위협만 평가한다. 상대 비밀의 정체를 읽거나 공개 개수만으로 아이언 돔을 추정하지 않는다. 모의 실행의 비용·소모·파괴·연쇄는 복사본에서 공통 규칙으로 처리하며 실제 전장/RNG와 고정 AI 덱을 변경하지 않는다.
