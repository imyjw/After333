# Generated character art source archive

These are the original generated atlases and the 512px intermediate exports from before the Animator Controller migration on2026-09-26. Their old.meta files are retained for provenance only; this directory is outside Unity Assets and is not imported or built.

Edit active game art under Assets/Unit/BlueDragon and Assets/Unit/Gwangma. The normal BlueDragon Idle remains the user's original four-frame animation. Export scripts read the original atlases here and default to a TempBuild export folder; they do not automatically update active art or clips.

Pre-migration Unit folders (including original PNGs/metadata/clips/controllers) are in ../Archive/BoardMotionsBeforeController_20260926.zip.
