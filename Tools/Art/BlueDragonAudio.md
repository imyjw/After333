# BlueDragon original sound design

Generated by `GenerateBlueDragonAudio.ps1` and `BlueDragonAudioSynthesizer.cs` from deterministic noise, filtered turbulence, resonant bubbles, pressure transients and nonverbal creature harmonics. No recordings, voice imitation, downloads or third-party code are used.

Regenerate from the repository root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Tools/Art/GenerateBlueDragonAudio.ps1
```

The execution-policy override applies only to that process. The script preserves existing Unity GUIDs. Close or refresh Unity as appropriate after generation; the script itself does not control the editor. `BlueDragonAudioValidation.json` records the generated clip measurements.

| Resource suffix | Trigger | Length | One-shot gain |
| --- | --- | ---: | ---: |
| WaterCannonCharge | Attack anticipation | 0.38 s | 0.26 |
| WaterCannonLaunch | Projectile release | 0.58 s | 0.55 |

Resource prefix: `Project333/Audio/BlueDragon/`. Cache clips once; use the battle presentation's shared 2D AudioSource or a bounded pool. Never create one AudioSource per droplet or transient. Preserve `After333AudioSettings` master volume through `AudioListener.volume`; do not multiply that master gain into one-shots a second time. Do not apply the music-only volume target to these effects.

All clips are mono 44.1 kHz 16-bit PCM, preloaded and decompressed on load. Combined sample payload is about 153 KiB, or 307 KiB decoded float data. Clip peaks remain below -1.7 dBFS before one-shot gain. Edges fade to zero to avoid discontinuity clicks. Gains are initial mix values and can be adjusted in actual gameplay listening.

Validation on 2026-09-26: generation compiled with the installed .NET C# compiler, all five actual WAV headers and sample payloads parsed independently, exact durations confirmed, zero clipped samples, first/last samples zero, absolute DC below 0.00008, unique audio GUIDs, and scoped whitespace check passed. Perceptual mix balance requires playback in the game; numerical validation does not replace listening.
